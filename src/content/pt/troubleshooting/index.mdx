# Perguntas frequentes

Esta página está em desenvolvimento. As perguntas frequentes sobre o DataSuite estão agrupadas por tema abaixo.

## Transferência e instalação [#faqs-download-install]

**P. Quais são os requisitos do sistema para o DataSuite?**

- Consulte a lista de [requisitos do sistema](/pt/docs/setup/requirements).

**P. Como sei que versão do DataSuite estou a utilizar?**

- Na barra de menus, clique em **Ajuda** e selecione **Sobre**.

![Caixa de diálogo Sobre do DataSuite com o número da versão](/images/datasuite_version_check.jpg)

**P. Como verifico manualmente se existem atualizações do DataSuite?**

- Na barra de menus, clique em **Ajuda** e selecione **Verificar atualizações**.

![Menu Ajuda com a opção Verificar atualizações em destaque](/images/datasuite_update_check.jpg)

**P. Como posso fazer uma desinstalação "limpa" do DataSuite?**

- Se pretender remover todos os dados do utilizador depois de [desinstalar](/pt/docs/setup/uninstall) o DataSuite, pode eliminar as pastas de dados do utilizador `DataSuite` e `.datasuite`.
- Isto repõe o sistema no estado anterior à instalação do DataSuite. Esta abordagem também pode ser utilizada para repor todas as definições, caso não pretenda desinstalar o DataSuite.
- A localização das pastas varia consoante a plataforma:
  - **Windows**: elimine `%APPDATA%\DataSuite` e `%USERPROFILE%\.datasuite`.

## DHIS2 Data Extractor

**P. Falha no início de sessão**

- Verifique o URL do DHIS2.
- Verifique as credenciais.

**P. Erros de exportação**

- Verifique as permissões dos ficheiros.
- Reveja a configuração do mapeamento.

## Configuração da análise

**P. Carregamento de dados: ficheiro Excel ou RDS?**

- Primeiro carregamento.
- Carregamentos seguintes.

**P. Não consigo localizar o ficheiro de cache gerado**

- Certifique-se de que [configurou corretamente a pasta de trabalho](/pt/docs/methodology/analysis-setup#working-folder). Depois, procure um ficheiro com um nome no formato `Countryname_yyyymmddhhms.rds`. Exemplo: `Somalia_202605241128.rds`.

**P. Onde obtenho os parâmetros de cobertura nacionais/subnacionais?**

- A confirmar.

**P. Onde estão os outros conjuntos de dados utilizados na análise de cobertura?**

- A confirmar.

**P. Não é gerado nenhum resultado depois de carregar os dados**

- Os dados foram ajustados?
- Todos os parâmetros de análise estão corretamente configurados?
