## Opções de instalação [#installer-options]

O DataSuite disponibiliza instalações Windows ao nível do **utilizador** e do **sistema**, bem como uma opção de instalação **portátil (.zip)**.

| Tipo de instalação | Descrição |
| --- | --- |
| Instalação de utilizador | **Recomendada para a maioria dos utilizadores.** Instala na pasta Local AppData do utilizador sem exigir privilégios de administrador. Permite atualizações contínuas em segundo plano. |
| Instalação do sistema | Instala em `Program Files` e exige privilégios de administrador. Disponível para todos os utilizadores do sistema, mas as atualizações também exigem elevação de privilégios. Utilize esta opção se precisar de acesso para vários utilizadores. |
| Modo portátil | Instala como uma pasta independente que pode ser movida entre ambientes. Todos os dados do DataSuite permanecem dentro da pasta. Ideal para utilização portátil em diferentes máquinas. Consulte [Modo portátil](/pt/docs/setup/portable) para ver as instruções de configuração. |

<Callout type="info">

O modo portátil é suportado apenas no pacote comprimido `.zip` do Windows, que não suporta atualizações automáticas.

</Callout>

## Atualização do DataSuite

Quando é lançada uma nova versão do CD2030 DataSuite com novas funcionalidades e correções importantes de erros, será convidado a instalar a nova versão ao abrir a aplicação DataSuite.

Pode também verificar manualmente se existem atualizações, selecionando **Ajuda** > **Verificar atualizações** no Windows.
