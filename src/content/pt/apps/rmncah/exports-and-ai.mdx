# Exportações, relatórios e IA

Este guia explica como retirar resultados do RMNCAH App, como construir um relatório e como o assistente de conversação do DataSuite pode analisar o mesmo conjunto de dados guardado. Para planear o que fazer com os resultados, consulte [Disseminação, decisões e ação](/pt/docs/framework/12-dissemination) e [Aproveitar a IA para análise e interpretação](/pt/apps/ai-assistant).

## Transferências na aplicação

| Onde | O que obtém |
| --- | --- |
| Barra de ferramentas do gráfico, **Baixar Gráfico** | O gráfico como imagem PNG |
| Barra de ferramentas do gráfico, **Baixar Dados** | Os números subjacentes ao gráfico como ficheiro Excel `.xlsx`, com folhas tituladas |
| Tabela, **Baixar Dados** | A tabela em Excel, para o ano ou indicador escolhido em *Apenas esta tabela* |
| Pontuação Geral da Qualidade dos Dados, Indicadores de DQA dos serviços, Sistema Nacional de Saúde | **Baixar Gráfico** (PNG) e **Baixar Dados** (Excel) para toda a tabela |
| Carregar dados, **Baixar Conjunto de Dados Principal** | O conjunto de dados combinado como ficheiro Stata `.dta` |
| Ajuste de dados, **Baixar Conjunto de Dados Ajustado** | O conjunto de dados ajustado como ficheiro `.dta` |

Alguns gráficos oferecem também ferramentas na barra de ferramentas do cartão: editar as etiquetas de um gráfico, alterar a orientação, o tamanho do texto ou a posição da legenda, ajustar o estilo (tipos de letra, cores, linhas de grelha) e expandir o gráfico. **Personalizar este gráfico** permite aplicar uma definição a este gráfico, a todos os gráficos do cartão, a todos os gráficos do mesmo tipo ou a todos os gráficos, e ao ecrã, ao relatório ou a ambos. As definições ficam guardadas com o conjunto de dados.

<Callout type="info">
Transfira os dados juntamente com o gráfico quando o partilhar. O ficheiro Excel inclui o título e os números, para que os leitores possam verificar a figura.
</Callout>

## Relatórios

A página **Relatórios**, na secção **Resultados**, constrói documentos (Word ou PDF) e apresentações (PowerPoint ou PDF) a partir do conjunto de dados carregado, começando pelos relatórios padrão desta aplicação ou por uma página em branco. Os gráficos e as tabelas são redesenhados a partir dos dados de cada vez, e cada relatório fica guardado no conjunto de dados. O guia completo, com cada relatório padrão, o editor, os formatos de exportação e a resolução de problemas, está na página [Relatórios](/pt/apps/rmncah/reports).

## Trabalhar com o assistente de conversação do DataSuite

O assistente de conversação do DataSuite trabalha sobre o mesmo conjunto de dados guardado que a aplicação, sabe em que página está e responde a partir dos seus dados e da metodologia Countdown, indicando as fontes. O que pode e não pode fazer, e as boas práticas, estão na página **[Assistente de IA](/pt/apps/ai-assistant)**.

<Steps>

### Conclua o carregamento do conjunto de dados

O assistente trabalha sobre o conjunto de dados `_rmncah.rds` guardado, que é criado quando conclui o assistente de Carregar dados.

### Abra a conversação e pergunte

Exemplos: *Lista as páginas da aplicação RMNCAH e o que cada uma lê*, *Que regiões têm cobertura de Penta3 abaixo de 80% no último ano, com o denominador selecionado?*, *Redige uma interpretação do contínuo de cuidados nacional para a reunião de revisão*.

### Verifique a resposta

Compare os números com a página correspondente da aplicação. O assistente termina a resposta com as suas fontes: os dados que usou e as secções da metodologia.

</Steps>

## Armadilhas comuns

- Partilhar um gráfico sem os respetivos dados ou sem o denominador. Indique sempre o denominador e o ajuste utilizados.
- Questionar o assistente sobre resultados antes de o Ajuste de dados ter sido executado e guardado na aplicação.
- Aceitar uma interpretação da IA sem verificar a qualidade dos dados. O assistente lê os mesmos dados, pelo que dados fracos originam conclusões fracas.
