# Preparação dos dados

A preparação dos dados transforma os dados reportados no conjunto de dados usado para a cobertura. Tem três páginas: **Remover anos**, **Ajuste de dados** e **Alterações no ajuste de dados**. As regras estão explicadas no capítulo **[ajuste de dados](/pt/docs/framework/3-data-adjustment)**.

<Callout type="important">
O ajuste é obrigatório. Os denominadores, a cobertura, as desigualdades, as metas e os Relatórios ficam indisponíveis até executar **Ajustar Dados** pelo menos uma vez.
</Callout>

## Remover anos

Use esta página para excluir anos cujos dados não são fiáveis, por exemplo um ano com quase nenhuma notificação ou uma falha conhecida do sistema.

<Steps>

### Decidir com base nas páginas de qualidade dos dados

Confirme nas páginas de **[qualidade dos dados](/pt/apps/vaxx/data-quality)** que um ano é inutilizável.

### Selecionar os anos

Em **Selecionar anos para remover**, escolha um ou mais anos.

### Confirmar

Escolha **Confirmar Remoção**. A caixa de mensagem indica então "Dados para os seguintes anos foram removidos" e lista-os. Para repor anos, limpe a seleção e confirme de novo ("Nenhum ano foi removido ainda.").

</Steps>

![Remover anos](/images/pt-dqa-remove-year.png)

A remoção ocorre antes do ajuste. Se já ajustou os dados, execute **Ajustar Dados** de novo depois de alterar os anos removidos.

## Ajuste de dados

A página tem dois cartões.

**Fatores K (Fatores de Ajuste)**: um **Fator K ANC**, um **Fator K Parto** e um **Fator K Vacinas**, cada um a escolher entre 0, 0,25, 0,5, 0,75 ou 1. O fator K é o volume de serviços que se assume nas unidades que não notificam, relativamente às que notificam. O valor por omissão do quadro é 0,25, e a página mostra os valores guardados no conjunto de dados.

**Ajustar**: **Ajustar Dados** aplica as correções ao conjunto de dados atual. O ajuste abrange as notificações em falta e os valores discrepantes extremos. A caixa de estado mostra "Ainda não ajustado", depois "Ajustando...", depois "Dados Ajustados". Depois de ajustados os dados, **Baixar Conjunto de Dados Ajustado** guarda `master_adj_dataset.dta`.

<Steps>

### Escolher os fatores K

Escolha um valor para cada um dos três fatores. Mantenha 0,25, a menos que tenha indícios de que as unidades que não notificam asseguram outra parte dos serviços, por exemplo um grande setor privado que notifica mal.

### Executar o ajuste

Escolha **Ajustar Dados** e aguarde por "Dados Ajustados".

### Rever as alterações

Abra **Alterações no ajuste de dados**.

</Steps>

![Escolha dos fatores K](/images/pt-adjustment-kfactor.png)

## Alterações no ajuste de dados

Mostra como o ajuste alterou cada indicador. Em **Visualizar efeitos das mudanças**, os separadores são **Nascidos vivos em estabelecimento de saúde**, **BCG**, **Pentavalente 1** e **Sarampo 1**, mais um separador **Verificação Personalizada** com um seletor de indicador. Cada gráfico compara o número do indicador antes e depois do ajuste de completude e de valores discrepantes.

Se os dados não foram ajustados, o gráfico usa um fator K de 0 para todos os serviços, pelo que mostra apenas o efeito do tratamento de valores discrepantes e em falta.

![Antes e depois do ajuste](/images/pt-adjustment-before-after.png)

## Interpretação e armadilhas

- Pequenas diferenças entre antes e depois são normais. Um grande salto num ano aponta para notificação muito baixa ou para um valor discrepante a rever na **[Detecção de valores discrepantes](/pt/apps/vaxx/data-quality)**.
- Segundo o quadro, os meses ou distritos com notificação inferior a 75% não são majorados, pelo que o ajuste não consegue reparar dados muito incompletos. Pondere remover esses anos.
- Alterar os fatores K, os anos removidos ou o limite de desempenho afeta todas as páginas seguintes. Execute **Ajustar Dados** de novo e reverifique os denominadores.
- Os relatórios e as caches agregadas devem ser criados a partir de dados ajustados. Consulte a **[Pooled App](/pt/apps/pooled)**.
