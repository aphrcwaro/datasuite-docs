# Primeiros passos

## Abrir a aplicação

Abra o DataSuite, vá à página Início e escolha **Vaxx**. A aplicação abre na página Introdução, que apresenta o projeto Countdown sobre cobertura vacinal e desigualdades em inglês, francês ou português. Use **Carregar dados** na navegação à esquerda para começar.

Se iniciar a aplicação ao abrir um ficheiro de dados no DataSuite, esse ficheiro é carregado por si.

## Ficheiros aceites

| Formato | Notas |
| --- | --- |
| `.xlsx`, `.xls` | Um livro com uma folha `Admin_data`, uma folha `Population_data`, uma folha `Reporting_completeness` e pelo menos uma folha `Service_data`. Inicia o percurso completo. |
| `.dta` | Um único ficheiro Stata, já combinado. |
| `.rds` | Um conjunto de dados guardado por esta aplicação. Já está validado, pelo que a aplicação abre um resumo do conjunto de dados em vez do percurso. |

São aceites ficheiros até 2 GB. As outras extensões são recusadas com "Falha no carregamento: Formato de arquivo não suportado."

Quando carrega um ficheiro Excel ou Stata, a aplicação procura uma cópia guardada com o nome `nome_vaccine.rds` e, se existir, carrega-a em seu lugar. É assim que o trabalho é retomado. Numa sessão de ambiente de trabalho, a cópia fica junto do seu ficheiro; num navegador, fica numa pasta local fixa.

## O assistente Carregar dados

O assistente tem uma lista de passos. Os passos desbloqueiam-se por ordem, e um passo obrigatório tem de estar concluído antes de o seguinte abrir.

<Steps>

### Carregar dados

Largue ou procure o seu ficheiro no cartão **Conjunto de dados** ("Procurar ou Soltar..."). Em Dados de referência adicionais (opcional), pode carregar as suas próprias **estimativas da ONU** e **estimativas WUENIC** para substituir os conjuntos de referência incorporados. **Baixar Conjunto de Dados Principal** guarda os dados combinados como `master_dataset.dta`. Limpar o ficheiro limpa também tudo o que dele deriva.

### Qualidade dos dados

As verificações são executadas automaticamente nas folhas carregadas. As verificações bloqueantes têm de ser aprovadas para poder continuar:

- As folhas Admin, População e Serviço são encontradas.
- O nome do país é reconhecido e a folha Admin indica apenas um país.
- A folha Admin tem as colunas país, admin-1 e distrito.
- Os distritos correspondem entre a folha Admin e todas as outras folhas, e os nomes de distrito são consistentes entre anos.
- Nenhum mês em falta em qualquer distrito-ano, e todos os valores de mês são meses reconhecidos em inglês ou francês.

As verificações informativas não bloqueiam. Assinalam nascidos vivos estimados inferiores às contagens institucionais reportadas, números de população que parecem colados nos dados de serviço, indicadores sem qualquer dado e nomes de meses escritos de forma diferente entre folhas. Duas verificações de mapeamento indicam os nomes de região do inquérito ou do ficheiro de forma que não correspondem aos seus dados.

### Ficheiros de inquérito (opcional)

Carregue, um de cada vez, os ficheiros de inquérito nacionais, regionais, por área, por educação materna e por quintil de riqueza (`.dta`). Sem eles, a aplicação mantém os seus dados de referência incorporados.

### Taxas nacionais

Confirme a cobertura do inquérito (percentagem, de 0 a 100) para CPN1, parto institucional, BCG, Penta1, Penta3, VOP1, VOP3 e Sarampo 1. Confirme as taxas nacionais (proporções, por exemplo 0,03 para 3%, intervalo de 0 a 0,05) de perda gestacional, nascimentos gemelares, natimortalidade, mortalidade neonatal e mortalidade pós-neonatal. Confirme também o Ano de Início dos Dados da Pesquisa e o Ano recente da pesquisa. Os valores encontrados no seu ficheiro de inquérito nacional são pré-preenchidos, por isso verifique-os. Todos os campos são obrigatórios.

### Ficheiro de forma (opcional)

Por omissão, é usado o ficheiro de forma padrão do país. Para usar o seu, carregue-o e indique que coluna contém os nomes de região (admin-1).

### Mapear inquérito e Mapear ficheiro de forma

Se carregou ficheiros de inquérito ou um ficheiro de forma personalizado, associe os nomes de região destes aos do seu conjunto de dados. Os nomes são associados automaticamente sempre que possível, mas tem de rever e guardar as correspondências mesmo que nada precise de correção.

### Concluir o carregamento dos dados

O conjunto de dados é guardado e o assistente mostra Pronto para análise, com um resumo (linhas carregadas, verificações aprovadas, campos definidos, ficheiros carregados, regiões mapeadas). Escolha **Continuar para a análise**. Use **Editar** no resumo para voltar a qualquer passo.

</Steps>

## Erros de carregamento comuns

| Mensagem ou sintoma | Significado e solução |
| --- | --- |
| Falha no carregamento: Formato de arquivo não suportado. | A extensão não é `.xls`, `.xlsx`, `.dta` nem `.rds`. |
| Falha no carregamento: missing sheet(s) | Falta uma folha obrigatória no livro. Os nomes em falta são listados. |
| Key Columns ... missing in ... | Falta uma coluna-chave numa folha, por exemplo a coluna do país ou do primeiro nível administrativo de `Admin_data`. |
| Sheet ... is empty. | Uma folha obrigatória não tem linhas. |
| Country contains multiple names. Please clean the data | A folha Admin indica mais do que um país. |
| The country in the document is not supported | Não foi possível associar o nome do país. É apresentada uma sugestão "Did you mean": corrija a grafia. |
| This dataset was built for the 'rmncah' indicator group, but this app is for 'vaccine'. | Carregou um conjunto de dados guardado pela RMNCAH App. Use essa aplicação ou recomece a partir dos dados originais. |
| Algumas verificações encontraram problemas a corrigir antes de poder continuar | Falhou uma verificação bloqueante de Qualidade dos dados. Corrija o ficheiro de origem e carregue-o de novo. |
| Arquivos obrigatórios ausentes, ou o arquivo não corresponde a nenhum padrão conhecido | Falta um ficheiro de inquérito ou não foi reconhecido. |
| Revisão necessária | As correspondências de nomes de região têm de ser revistas e guardadas antes de continuar. |

<Callout type="info">
Se não for possível ler uma cópia `.rds` guardada, a aplicação volta automaticamente ao ficheiro Excel ou Stata original.
</Callout>
