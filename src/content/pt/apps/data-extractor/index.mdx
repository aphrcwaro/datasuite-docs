# CD2030 DHIS2 Data Extractor

O **CD2030 DHIS2 Data Extractor** ajuda as equipas a ligar-se ao DHIS2, preparar metadados, mapear indicadores e transferir dados de rotina de uma forma mais estável e mais fácil de reproduzir do que a extração manual.

Foi concebido para suportar transferências grandes, com vários períodos, reduzindo a sobrecarga do servidor, evitando pedidos repetidos desnecessários e preservando o progresso através da cache local.

<Callout type="info">

**Aviso de acesso:** o CD2030 DHIS2 Data Extractor não permite o acesso não autorizado aos dados do DHIS2.

</Callout>

## O que o extrator faz

O extrator suporta um fluxo de trabalho prático e completo:

<Mermaid
  chart={`
flowchart TD
  A["1. Iniciar sessão no DHIS2"]
  B["2. Sincronizar, ler e guardar em cache os metadados"]
  C["3. Mapear os metadados de origem para os indicadores"]
  D["4. Transferir os dados de rotina"]
  E["5. Guardar o mapeamento para exportação ou reutilização"]
  A --> B --> C --> D --> E
`}
/>

Este processo ajuda os analistas a obter um ponto de partida mais limpo e mais reproduzível para as análises seguintes no DataSuite.

## Etapas de início rápido

<Steps>

### [Iniciar sessão no DHIS2](/pt/apps/data-extractor/dhis2-login)

Ligue-se à instância correta do DHIS2 utilizando o URL do servidor e credenciais de conta válidas.

### [Guardar os metadados em cache](/pt/apps/data-extractor/dhis2-login#read-and-cache-metadata)

Guarde temporariamente (em cache) os metadados localmente, para um acesso rápido e uma transferência eficiente.

### [Escolher um modo de mapeamento](/pt/apps/data-extractor/mapping#map-metadata)

Utilize o mapeamento **Countdown** para o modelo MNCH harmonizado ou o mapeamento **Custom** para outros programas.

### [Transferir os dados](/pt/apps/data-extractor/data-download)

Execute a extração com pedidos mais pequenos e reutilize os metadados em cache para minimizar transferências repetidas.

</Steps>
