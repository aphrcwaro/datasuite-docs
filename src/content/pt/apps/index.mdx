# Aplicações do DataSuite

O CD2030 DataSuite inclui um conjunto de aplicações integradas, concebidas para apoiar a análise de dados de rotina das unidades de saúde.
Cada aplicação desempenha uma função específica no fluxo de trabalho analítico, da extração de dados à análise e à elaboração de relatórios.

| Aplicação | Utilize para | Entrada |
| --- | --- | --- |
| [Data Extractor](/pt/apps/data-extractor) | Extrair dados de rotina do DHIS2 e mapeá-los para indicadores padrão | Uma instância DHIS2 |
| [RMNCAH App](/pt/apps/countdown) | Analisar de ponta a ponta indicadores de saúde reprodutiva, materna, neonatal, infantil e do adolescente | `.xls`, `.xlsx`, `.dta`, `.rds` |
| [Vaxx App](/pt/apps/countdown) | Analisar a cobertura vacinal e as desigualdades | `.xls`, `.xlsx`, `.dta`, `.rds` |
| [Pooled App](/pt/apps/pooled) | Agrupar as análises guardadas de vários países ou conjuntos de dados para comparação regional | Uma pasta de caches `.rds` |

## [CD2030 Data Extractor](/pt/apps/data-extractor)

O Data Extractor liga-se a sistemas DHIS2 e permite aos utilizadores extrair e mapear dados de rotina das unidades de saúde em formatos padronizados para análise.

[Ir para o Data Extractor →](/pt/apps/data-extractor)

## [RMNCAH App](/pt/apps/countdown)

O RMNCAH App apoia a análise de indicadores de saúde reprodutiva, materna, neonatal, infantil e do adolescente, aplicando a abordagem analítica padronizada do CD2030. Abrange a qualidade dos dados, os denominadores, a cobertura, a equidade e a análise subnacional, e acrescenta páginas de análise bayesiana, continuum de cuidados, planeamento familiar, mortalidade, utilização de serviços e sistema de saúde.

[Ir para o RMNCAH App →](/pt/apps/countdown)

## [Vaxx App](/pt/apps/countdown)

O Vaxx App centra-se na vacinação. Segue as mesmas etapas analíticas do RMNCAH App (qualidade dos dados, ajuste, denominadores, cobertura, desigualdades e metas, a nível nacional e subnacional) para indicadores de vacinação.

[Ir para o Vaxx App →](/pt/apps/countdown)

## [Pooled App](/pt/apps/pooled)

O Pooled App destina-se à **análise regional e multinacional**. Carrega, a partir de uma pasta, as caches guardadas pelas aplicações RMNCAH e Vaxx, permite escolher o domínio (RMNCAH ou Imunização), processa o conjunto de dados selecionado e exporta o resultado agrupado em CSV ou Excel.

[Ir para o Pooled App →](/pt/apps/pooled)
