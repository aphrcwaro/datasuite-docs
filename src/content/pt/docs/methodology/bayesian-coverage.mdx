# Abordagem de modelação bayesiana

Foi desenvolvido um modelo estatístico para estimar a cobertura em saúde a nível nacional e para regiões subnacionais até ao ano mais recente com dados, e para fazer previsões de curto prazo para os anos seguintes.

<Callout type="info">
**Em resumo**
- **Responde a:** Qual é a melhor estimativa da cobertura em cada ano, a nível nacional e para as regiões subnacionais, até ao ano mais recente com dados e para os anos seguintes, e qual é a sua incerteza?
- **Utiliza:** dados de inquérito (os seus níveis de cobertura, ponderados pela sua incerteza) e dados de rotina das unidades de saúde (apenas a sua tendência de ano para ano, a partir da [Cobertura nacional](/pt/docs/methodology/coverage)), com a pontuação média de qualidade dos dados do Countdown da [Avaliação da qualidade dos dados](/pt/docs/methodology/data-quality).
- **Produz:** para a CPN4, os partos institucionais e a cobertura vacinal (três doses de pentavalente), uma melhor estimativa para cada ano com um intervalo de incerteza de 95%, a nível nacional e por região, e previsões de curto prazo. Passo seguinte: [Avaliação da equidade (equiplots)](/pt/docs/methodology/equity).
- **Nas aplicações:** [Análise bayesiana](/pt/apps/countdown/advanced-analysis#bayesian-analysis) (apenas aplicação RMNCAH).
</Callout>

## Porque é importante

Informações fiáveis sobre os indicadores de cobertura em saúde são essenciais para monitorizar o progresso, orientar os programas e fundamentar decisões de política. No entanto, depender apenas de dados de inquérito e de rotina é frequentemente difícil. Os dados de rotina das unidades de saúde podem sofrer de subnotificação ou de qualidade de dados inconsistente, enquanto os dados de inquérito podem ser incertos ou não recentes.

Para responder a estes desafios, podem ser utilizados modelos estatísticos para produzir estimativas e previsões ao longo do tempo, combinando múltiplas fontes de dados e tendo em conta as suas limitações. Isto resulta em estimativas de cobertura para cada ano (entre pontos de dados e dados passados) com uma indicação do grau de certeza/incerteza sobre cada ano. Assim, os modelos permitem avaliações da cobertura em saúde mais completas, precisas e oportunas, especialmente em contextos com dados limitados.

O modelo é a ferramenta a utilizar quando os inquéritos são antigos ou poucos e os dados das unidades de saúde são imperfeitos, e é necessária uma única tendência defensável, por exemplo para um relatório de síntese.

## Método

### Produção de estimativas e previsões de curto prazo

O modelo analisa os dados disponíveis e identifica diferentes formas como a cobertura pode ter evoluído ao longo do tempo. Cada um destes percursos possíveis é designado por **trajetória** (ver a figura na secção sobre como são utilizados os dados de inquérito).

Para cada ano, é apresentada uma melhor estimativa (o valor central de todas as trajetórias) e um intervalo que mostra a incerteza (excluindo as possibilidades mais extremas nas margens).

Com base em análises globais, o modelo reflete que, ao longo do tempo, a cobertura tende a subir de níveis baixos para níveis elevados, seguindo uma tendência em forma de S, com períodos de progresso mais rápido ou mais lento consoante o que os dados indicam. Utiliza dados de inquérito e de rotina para escolher as trajetórias que correspondem ao observado. O modelo baseia-se também em tendências observadas noutras áreas com níveis de cobertura semelhantes.

### Como são utilizados os dados de inquérito?

Os dados de inquérito ajudam a compreender a cobertura, mas trazem alguma incerteza. Isto acontece porque os inquéritos incluem apenas uma amostra da população, e não todas as pessoas, e podem ocorrer erros durante a recolha de dados.

Para tirar o melhor partido dos dados de inquérito, o modelo procura encontrar o equilíbrio certo, suavizando as oscilações aleatórias que provavelmente não são reais, sem deixar de captar os padrões importantes nos dados. Para tal, o modelo analisa o grau de incerteza de cada ponto de dados:

- **Incerteza elevada:** se um ponto de dados for muito incerto, terá menos impacto na cobertura estimada (o modelo atribui-lhe menos peso e tende a suavizá-lo).
- **Fiabilidade elevada:** se um ponto de dados for mais fiável, as estimativas ficarão mais próximas desse valor.

Para as regiões subnacionais, o modelo utiliza os dados de inquérito da região específica, quando disponíveis.

![Trajetórias possíveis da cobertura ao longo do tempo com base nos dados de inquérito](/images/bayesian1-coverage-over-time.png)

### Como são utilizados os dados de rotina?

As estimativas de cobertura a partir de dados de rotina podem ser enviesadas, pelo que o modelo trata-as de forma diferente dos dados de inquérito. Para os inquéritos, o modelo utiliza os níveis reais de cobertura. Por exemplo, se um inquérito indicar uma cobertura de 60% para um determinado ano, o modelo utiliza esse valor diretamente.

Em contrapartida, os dados de rotina podem ser enviesados devido a problemas como a notificação incompleta e inconsistências na recolha de dados. Por esse motivo, o modelo não se baseia nos níveis de cobertura observados nos dados de rotina. Em vez disso, o modelo concentra-se na **tendência ao longo do tempo**, ou seja, na forma como a cobertura varia de ano para ano.

- **Exemplo:** se os dados de rotina mostrarem a cobertura a aumentar de 50% em 2020 para 53% em 2021, o modelo interpreta isto como um aumento de 3 pontos percentuais. Se os dados de rotina mostrarem variações mais rápidas ou mais lentas do que o esperado, o modelo ajusta as estimativas, mas apenas na medida em que os dados sejam de confiança.

<Callout type="info">

**Ter em conta a qualidade dos dados**

O modelo tem em conta a qualidade dos dados de rotina ajustando a incerteza das estimativas de tendência. As observações com menor qualidade de dados são tratadas como mais incertas e recebem menos peso na determinação das taxas reais de variação. Especificamente, a incerteza na taxa de variação estimada aumenta à medida que a pontuação média de qualidade dos dados do Countdown diminui. Consequentemente, os dados de menor qualidade exercem menos influência na taxa de variação modelada.

</Callout>

São produzidas estimativas para:

- A proporção de mulheres que recebem o mínimo recomendado de pelo menos quatro consultas de cuidados pré-natais durante a gravidez (**CPN4**).
- A proporção de nados-vivos que ocorrem numa unidade de saúde (**Partos institucionais**).
- A proporção de crianças que recebem as três doses recomendadas da vacina pentavalente (**Cobertura vacinal**).

- Os gráficos mostram que as estimativas do modelo geralmente seguem os dados de inquérito, a menos que um ponto de dados seja muito incerto e não corresponda à tendência geral.
- Por exemplo, na **Região B**, o ponto de inquérito MICS mais recente é mais baixo do que o esperado e muito incerto, pelo que as estimativas recentes do modelo não se alinham exatamente com esse inquérito.
- Observa-se também que os dados de rotina ajudam a indicar a rapidez com que a cobertura está a variar ao longo do tempo, particularmente após o inquérito mais recente, quando não existem novos dados de inquérito disponíveis.
- **Região C:** os dados de rotina mostram um aumento da cobertura. Em consequência, as estimativas que incluem os dados de rotina mostram uma taxa de variação mais rápida durante esse período, em comparação com as estimativas baseadas apenas nos dados de inquérito.
- **Região D:** os dados de rotina sugerem que a cobertura não aumentou recentemente, e as estimativas que incluem os dados de rotina refletem essa informação.

</Callout>

### Leitura das estimativas

Uma faixa estreita significa que os dados concordam; uma faixa larga significa poucos pontos de dados ou dados em conflito. A estimativa segue uma subida em forma de S, típica da cobertura. Não encare o modelo como substituto de bons dados: se a pontuação de qualidade dos dados de rotina for baixa, a estimativa apoia-se mais nos inquéritos.

### Armadilhas comuns

- Utilizar estimativas bayesianas sem indicar que são modeladas. Identifique-as como tal nos relatórios.

## Nas aplicações

<Steps>

### Abra a Análise bayesiana

Na aplicação RMNCAH, o grupo **Análise bayesiana** da barra lateral tem duas entradas: **Análise nacional** e **Análise subnacional** (regiões). A aplicação Vaxx não tem estas páginas.

### Escolha um separador de indicador

Cada separador é um indicador para o qual o modelo está definido: a [Análise bayesiana](/pt/apps/countdown/advanced-analysis#bayesian-analysis) apresenta a lista.

### Leia o gráfico

A linha central é a melhor estimativa e a faixa é o intervalo de incerteza; **Baixar Gráfico** e **Baixar Dados** estão na barra de ferramentas. Identifique as estimativas como modeladas quando as utilizar em relatórios.

</Steps>
