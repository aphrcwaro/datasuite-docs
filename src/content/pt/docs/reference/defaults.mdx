# Valores predefinidos e limiares

Os números que o método utiliza -- valores predefinidos, limiares e intervalos esperados -- reunidos num só lugar, agrupados por etapa da análise. Cada linha indica o que é o valor, se se aplica às análises RMNCAH, às análises de vacinação ou a ambas, como as aplicações o utilizam e que secção da [metodologia Countdown](/pt/docs/methodology) o explica.

Os valores são gerados a partir do código das aplicações (cd2030.core), pelo que são os que as aplicações utilizam. Quando o guia de vacinação Countdown de 2024 difere, a página da metodologia indica-o.
