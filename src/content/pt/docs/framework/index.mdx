# Visão geral da estrutura

Esta página resume a estrutura analítica do CD2030 DataSuite.
Destina-se a ajudar as equipas a passar dos dados brutos das unidades de saúde e dos inquéritos para resultados defensáveis de cobertura a nível nacional e subnacional.

![Fluxo de trabalho da análise Countdown](/images/methods_cd_approach.png)

## Fluxo de trabalho de ponta a ponta

A estrutura segue uma sequência prática:

1. [Carregar e configurar](/pt/docs/framework/1-analysis-setup) os dados das unidades de saúde e dos inquéritos.
2. [Calibrar as principais taxas de referência nacionais](/pt/docs/framework/1-analysis-setup#survey-params).
3. [Avaliar a qualidade dos dados](/pt/docs/framework/2-data-quality-assessment) antes de estimar a cobertura.
4. [Ajustar](/pt/docs/framework/3-data-adjustment) os dados incompletos, instáveis ou pouco confiáveis.
5. [Selecionar o denominador com melhor desempenho](/pt/docs/framework/4-denominator-selection).
6. Gerar e interpretar os resultados de **[cobertura](/pt/docs/framework/5-coverage-estimation)**, **[equidade](/pt/docs/framework/6-equity-analysis)**, **[subnacionais](/pt/docs/framework/7-subnational-analysis)**, **[mortalidade](/pt/docs/framework/9-mortality)**, **[utilização de serviços](/pt/docs/framework/10-service-utilisation)** e **[desempenho do sistema de saúde](/pt/docs/framework/11-health-system-performance)**.

O objetivo final da estrutura é a utilização prática. As conclusões devem informar os processos de revisão do país, as discussões de planeamento e os grupos de trabalho técnicos, para que a análise conduza a ações concretas de SRMNIA (RMNCAH) em vez de permanecer apenas como um relatório isolado.
