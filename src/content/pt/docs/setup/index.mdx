# Configuração do CD2030 DataSuite

O CD2030 DataSuite funciona atualmente em sistemas operativos Windows. É uma plataforma leve que permite instalá-la ou usar uma versão portátil e iniciar as operações com dados em poucos minutos.

Para começar, siga estas instruções de configuração passo a passo:

<Steps>

### Reveja os [requisitos do sistema](/pt/docs/setup/requirements)

- Para garantir que o equipamento e a configuração do computador são compatíveis.

### Transfira e instale o CD2030 DataSuite para a sua plataforma

- Selecione a opção de [instalador](/pt/downloads#installer-options) adequada ao seu PC.
- [Instale](/pt/docs/setup/windows) a aplicação DataSuite.

### Aceda a [Primeiros passos com o DataSuite](/pt/docs/getting-started)

- Para conhecer a interface do utilizador (UI) e as principais funcionalidades do CD2030 DataSuite.

</Steps>
