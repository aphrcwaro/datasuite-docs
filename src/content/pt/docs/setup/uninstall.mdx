# Desinstalar o DataSuite

Os passos para desinstalar o DataSuite dependem da plataforma e da opção de instalação utilizada. Por exemplo, no Windows, pode usar os instaladores Windows **System** ou **User**, ou transferir um ficheiro `.zip` e extrair o seu conteúdo para qualquer local da máquina.

Em geral, deve desinstalar o DataSuite como qualquer outra aplicação de secretária, seguindo o fluxo recomendado pela plataforma para remover software. Mais abaixo são fornecidas orientações específicas por plataforma, bem como instruções sobre como [limpar completamente](#clean-uninstall) quaisquer ficheiros de configuração do DataSuite que permaneçam.

## Windows

### Instalador do Windows

Se instalou o DataSuite através do instalador do Windows, seja a versão **User** ou **System**, utilize o próprio instalador para remover o DataSuite.

- Menu Iniciar
  - Pesquise **Adicionar ou remover programas** e encontre o DataSuite na lista **Aplicações** > **Aplicações e funcionalidades**.
  - Selecione **Desinstalar** no menu de ações à direita (três pontos verticais).
  - Siga as instruções para desinstalar o DataSuite.
- Painel de Controlo
  - Em **Programas**, selecione a ligação **Desinstalar um programa**.
  - Encontre a entrada do DataSuite, clique com o botão direito do rato e selecione **Desinstalar**.
  - Siga as instruções para desinstalar o DataSuite.

### Instalação através do ficheiro .zip

Se instalou o DataSuite no Windows ao transferir e extrair um dos ficheiros `.zip` disponíveis na [página de transferências do DataSuite](/pt/downloads), pode desinstalá-lo eliminando a pasta onde extraiu o conteúdo do ficheiro `.zip`.

## Desinstalação completa [#clean-uninstall]

Se pretender remover todos os dados do utilizador após desinstalar o DataSuite, pode eliminar as pastas de dados do utilizador `DataSuite` e `.datasuite`. Isto devolve o sistema ao estado anterior à instalação do DataSuite. Também pode ser usado para repor todas as definições, caso não queira desinstalar o DataSuite.

A localização das pastas varia consoante a plataforma:

- **Windows**: elimine `%APPDATA%\DataSuite` e `%USERPROFILE%\.datasuite`.
