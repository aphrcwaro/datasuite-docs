## Instalar o DataSuite no Windows [#datasuite-install]

### Utilizar o instalador do Windows

<Steps>

### Transfira o [instalador do DataSuite](/pt/downloads) para Windows

### Depois de transferido, execute o instalador (`DataSuiteUserSetup-{version}.exe`)

Se aparecer um aviso do Controlo de Conta de Utilizador (UAC), clique em **Sim** para permitir que a aplicação faça alterações no seu dispositivo.

### Aceitar o contrato de licença

Leia o Contrato de Licença de Utilizador Final (EULA). Selecione **I accept the agreement** (Aceito o contrato) e clique em **Next** (Seguinte).

![Ecrã do contrato de licença do instalador do DataSuite](/images/install_accept_licence.jpg)

### Escolher o local de instalação

Escolha a pasta de destino onde pretende instalar o DataSuite. Por predefinição, o DataSuite é instalado em `C:\Users\{Username}\AppData\Local\Programs\DataSuite`. Clique em **Next** (Seguinte) para continuar.

![Ecrã do local de instalação do instalador do DataSuite](/images/install_choose_location.jpg)

### Instalar e concluir

Clique em **Install** (Instalar) para iniciar o processo. Quando a barra de progresso terminar, clique em **Finish** (Concluir) para fechar o assistente de instalação e iniciar o DataSuite.

![Ecrã de instalação pronta do instalador do DataSuite](/images/install_datasuite.jpg)

</Steps>

### Utilizar o ficheiro ZIP

1. Transfira o [ficheiro ZIP do DataSuite](/pt/downloads).
1. Extraia o ficheiro ZIP e execute o DataSuite a partir daí.
