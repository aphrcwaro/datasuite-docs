# Navegar pela interface do CD2030 DataSuite

Nesta página encontra instruções sobre os vários ecrãs e vistas, além de dicas para navegar no CD2030 DataSuite como utilizador principiante.

Depois de [transferir](/pt/downloads) e [instalar](/pt/docs/setup/windows#datasuite-install) o CD2030 DataSuite, verá o seguinte ecrã:

![Página inicial do DataSuite com os elementos da interface numerados](/images/welcome-page-annotated.png)

Tem os seguintes elementos:

<Steps>

### Página inicial (Welcome)

Este é o ecrã inicial predefinido ao abrir o DataSuite. Oferece:

- Acesso rápido às aplicações principais
- Pontos de entrada para novos utilizadores e ligações para tutoriais guiados

### Ficheiro (File)

O menu **Ficheiro** dá acesso às ações e à navegação ao nível da aplicação.

As principais funções incluem:

- Ver todas as aplicações disponíveis no DataSuite
- Abrir ou alternar entre ferramentas
- Gerir os editores abertos (fechar separadores)
- Sair da aplicação

### Ver (View)

O menu **Ver** controla a forma como a aplicação é apresentada e organizada.

Pode:

- Alterar o tema da aplicação (por exemplo, modo claro/escuro)
- Aumentar ou diminuir o zoom da interface
- Ajustar o esquema e a organização dos painéis
- Alterar as definições de idioma

### Ajuda (Help)

O menu **Ajuda** dá acesso a recursos de apoio e a informações do sistema.

As principais funcionalidades incluem:

- Aceder à documentação do DataSuite
- Verificar a versão atual da aplicação e procurar atualizações
- Ver informações técnicas e de programador

### Abrir o Data Extractor (Open Data Extractor)

Inicia o Data Extractor, usado para ligar ao DHIS2, mapear indicadores e transferir dados de rotina das unidades de saúde.

### Abrir no RMNCAH (Open in RMNCAH)

Inicia a RMNCAH App, usada para:

- Analisar indicadores de saúde materna, neonatal, infantil e do adolescente
- Gerar resultados analíticos e relatórios

</Steps>
