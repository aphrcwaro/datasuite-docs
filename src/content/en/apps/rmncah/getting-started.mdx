# Getting started

This guide takes you from opening the RMNCAH App in DataSuite to a dataset that is ready for analysis. The methodology behind these steps is described in [Analysis setup](/en/docs/framework/1-analysis-setup).

## Open the app

<Steps>

### Start the app from DataSuite

On the DataSuite welcome page choose **Open in RMNCAH** (see [Navigating the DataSuite interface](/en/docs/getting-started)). The app needs a file to work on, so DataSuite asks you to pick one. Accepted types are `.xls`, `.xlsx`, `.dta` and `.rds`.

Use the Excel workbook from the [Data Extractor](/en/apps/data-extractor) the first time, and the saved `.rds` afterwards.

### Check that the file was read

Open **Load Data** in the sidebar. When DataSuite hands the file to the app, it is read automatically and a green **Upload successful** banner names the file. If the page shows an **Upload HFD data** box instead, choose the file there.

</Steps>

![Loading routine data](/images/rmncah-loading-data.jpg)

## Two ways through Load Data

- **A resumed `.rds` file** was already validated. The wizard is replaced by a **Ready for analysis** page with one row per step (for example *15 of 15 fields set*, *Using the built-in shapefile*) and an **Edit** link that reopens any step. **Continue to analysis** takes you to Reporting Rate.
- **A new Excel or Stata file** goes through the walkthrough below. A step opens only after you press **Continue** (or **Skip to**) on the previous one. Steps marked *optional* can be skipped.

## The wizard steps

<Steps>

### Upload Data

The **Dataset** card shows the loaded file. **Download Master Dataset** saves the merged dataset as a `.dta` file.

The card **Additional reference data (optional)** lets you replace the built-in country reference sets with your own `.dta` files: **Upload UN Estimates data**, **Upload WUENIC estimates** and **Upload UN Mortality estimates**. **Restore default** returns to the built-in data.

### Data Quality

The checks run automatically. A banner reads either *All checks passed, no blocking issues found* or *Some checks found issues that need fixing before you can continue*.

- **Blocking checks:** Admin, Population and Service sheets found; country, admin-1 and district columns present; exactly one country, recognised by name; districts match between the Admin sheet and every other sheet; district names consistent across years; no missing months (every district-year has all 12); every month name recognised (English or French).
- **Informational checks:** estimated live births not lower than facility live births (10% margin), population data not pasted into service data, every indicator has some data, month names labelled consistently across sheets.
- **Mapping checks:** survey and shapefile region names match your dataset. Mismatches are fixed in the mapping steps.

Fix blocking problems in the workbook and load it again.

### Survey Files (optional)

Upload up to five `.dta` files in the **Survey data folder** card: **National data**, **Regional data**, **Area data**, **Maternal education data** and **Wealth index quintile data**. They power equity analysis, survey comparison lines and sub-national comparisons. A file that cannot be read shows *Upload failed* with the reason.

### National Rates

Enter the survey values used to derive denominators. Every field is required and **Continue** stays disabled while *Required fields remaining* is shown.

- **Survey reference:** **Recent Survey Year** (2015 to 2030) and **Survey Data Start Year**. Use the two most recent surveys, for example 2018 when surveys exist for 2008, 2013, 2018 and 2023.
- **Maternal and newborn:** ANC1, ANC4, Institutional Delivery, C-Section and Low Birth Weight coverage as percentages (0 to 100), and Pregnancy Loss, Twin Births, Stillbirth, Neonatal Mortality and Post-Neonatal Mortality as proportions (0 to 0.05, for example 0.03 means 3%).
- **Immunization:** BCG, Penta1, Penta3 and Measles 1 coverage as percentages.

If you uploaded a national survey file, the values are pre-filled and a banner says so. Check them. The definitions are in the [methodology](/en/docs/framework/1-analysis-setup#survey-params).

![National rates for denominator calculation](/images/national-surveys.png)

### Shapefile (optional)

The app uses a built-in shapefile for the country. To use your own, upload the `.shp`, `.dbf`, `.shx` and `.prj` files, pick the column that holds the region (admin-1) names and press **Use this shapefile**.

### Map Survey and Map Shapefile

When survey or shapefile region names differ from your dataset, press **Match Region Names**, correct the matches and save. Save at least once, even if nothing needed changing. **Clear mapping** starts again.

### Finish

On the last step press **Finish Loading Data**. The app merges the sheets, saves a copy named after your file with `_rmncah.rds` added, in the same folder, and shows **Ready for analysis**.

</Steps>

<Callout type="info">
When you open the same Excel or Stata file again, the saved `_rmncah.rds` copy next to it is used instead. Delete that copy if you changed the workbook and want to load it afresh.
</Callout>

## Troubleshooting

| Message | Cause and fix |
| --- | --- |
| Upload failed: Unsupported file format. | The file is not `.xls`, `.xlsx`, `.dta` or `.rds`. Convert it or export again. |
| Upload failed: The file provided does not exist | The selected path is missing or was moved. Select the file again. |
| Upload failed followed by a detail | The workbook could not be read, for example a required sheet or column is absent. Compare it with the sheet list under Data Quality. |
| This dataset was built for the 'vaccine' indicator group, but this app is for 'rmncah'. | A saved dataset from another Countdown app was opened. Use the matching app or load the workbook. |
| Some checks found issues that need fixing | A blocking Data Quality check failed. Read the red row, correct the workbook, load it again. |
| Complete the earlier steps first | You tried to jump ahead. Finish or skip the current step. |
| Some survey region names do not match your dataset | Use **Match Region Names** in the mapping step. |
| Load and finish a dataset first to unlock this page | Analysis pages stay locked until loading is finished. |

After loading, continue with [Data quality](/en/apps/rmncah/data-quality).
