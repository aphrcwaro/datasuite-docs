# RMNCAH App overview

The RMNCAH App within the CD2030 DataSuite is designed to support the analysis of routine health facility data for key RMNCAH indicators.
It provides a standardized framework for transforming raw DHIS2 data into meaningful insights on service coverage, data quality, and equity.

Building on the outputs from the **[Data Extractor](/en/apps/data-extractor)**, the RMNCAH App guides users through a **[structured analytical workflow](/en/docs/framework)** that includes data validation, adjustment, and indicator computation.
This ensures that analyses are consistent, reproducible, and aligned with the **[CD2030 methodological approach](/en/docs/framework/0-workflow)**.

The app enables users to:

- Assess data quality through standardized DQA metrics
- Apply numerator and denominator adjustments
- Generate national and subnational coverage estimates
- Explore inequalities and trends across time and geography
- Produce outputs for reporting, including synthesis reports and visualizations

By integrating methodological rigor with a user-friendly interface, the RMNCAH App facilitates evidence-based decision-making and supports countries in monitoring progress across RMNCAH priorities.

## Who uses it

The app is written for the country analytical team of a CD2030 review: monitoring and evaluation officers, HMIS and DHIS2 data managers, programme managers for maternal, newborn, child and adolescent health, and the analysts who prepare annual health sector reviews. You do not need to write code. Everything is done through pages, filters, charts and tables. Analysts who prefer scripting can work on the same saved dataset through the DataSuite chat assistant (see [Exports, reports and AI](/en/apps/rmncah/exports-and-ai)).

## What you can load

The app opens one dataset at a time. It accepts four file types:

| File type | What it is | Typical use |
| --- | --- | --- |
| `.xlsx`, `.xls` | Excel workbook with the sheets Admin_data, Population_data, Reporting_completeness and at least one Service_data sheet, as produced from the [Data Extractor](/en/apps/data-extractor) | First load of a country dataset |
| `.dta` | Stata file | First load, or a master dataset downloaded earlier |
| `.rds` | The saved dataset that the app creates when you finish loading | Resuming work: every loading step is already done |

During the load wizard you can also add optional survey files (`.dta`), a custom shapefile and country-specific UN, WUENIC and UN mortality reference files (`.dta`). Built-in reference data for the country are used when you add nothing. See [Getting started](/en/apps/rmncah/getting-started).

## How it relates to the Data Extractor and the methodology

- The **[Data Extractor](/en/apps/data-extractor)** produces the routine data file. The RMNCAH App starts where the extractor stops.
- The **[methodology chapters](/en/docs/framework)** explain why each analysis is done and how to interpret it. Every page guide in this section ends with a link to the matching chapter, and the **Get Help** button in the app opens the same chapters.

## Layout and navigation

![RMNCAH App navigation panes](/images/rmncah_ui.jpg)

- **Sidebar.** The pages are grouped in five sections: **Start**, **Data quality**, **Denominators**, **Analysis** and **Output**. **Change Language** at the top switches the app between English, French and Portuguese.
- **Locked pages.** Pages are greyed out until they can be used. Load Data is always open. The Denominators and Analysis groups and Reports unlock only after you have finished loading a dataset and run **Data Adjustment**.
- **Page header.** Each page shows its title and a one-line subtitle. **Get Help** opens the matching methodology chapter. Pages that feed a standard report also show **Generate Report**. Analysis pages show a *Denominator* row that tells you which denominators the numbers were divided by; it is set on the Denominator Selection page.
- **Filter bar.** Filters appear as chips at the top of a page, for example **Indicator**, **Admin Level**, **Performance Threshold** or **Select Years**.
- **Chart cards.** A card usually has one tab per indicator plus a **Custom** tab where you pick any other analysis indicator. The card toolbar downloads the chart (**Download Plot**, PNG) or its numbers (**Download Data**, Excel), and offers tools to edit labels, change the view or style, and expand the chart.
- **Tables.** A control marked *This table only* (year or indicator) changes that table alone. Each table has its own **Download Data** button.

| Data preparation | Remove Years, Data Adjustment, Data Adjustment Changes | Exclude unreliable years and correct for incomplete reporting | [Data preparation](/en/apps/rmncah/data-preparation) |

| Sub-national analysis | Sub-National Coverage, Sub-National Inequality, Coverage Target | Regional and district coverage, spread and targets | [Sub-national analysis](/en/apps/rmncah/subnational) |
| Advanced analysis | Bayesian Analysis, Continuum of Care, FPET FP Projection | Modelled estimates, care pathway, family planning | [Advanced analysis](/en/apps/rmncah/advanced-analysis) |
| Mortality | Institutional Mortality, Mortality Mapping, Mortality Completeness | Institutional maternal, stillbirth and neonatal mortality and how completely deaths are reported | [Mortality](/en/apps/rmncah/mortality) |
| Service utilization and health system | Service Utilization, MCH Preventive vs Curative Index, Health System Performance, Public/Private Share | Outpatient and inpatient use, health system inputs and the private sector | [Service utilization and health system](/en/apps/rmncah/service-utilization-health-system) |
| Output | Reports | Word, PDF and PowerPoint reports (standard reports, synthesis chartbook, one-pager), downloads and AI-assisted analysis | [Reports](/en/apps/rmncah/reports), [Exports, reports and AI](/en/apps/rmncah/exports-and-ai) |
