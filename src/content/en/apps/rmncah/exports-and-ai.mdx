# Exports, reports and AI

This guide covers how to take results out of the RMNCAH App, how to build a report, and how the DataSuite chat assistant can analyse the same saved dataset. For planning what to do with the results, see [Dissemination, decisions and action](/en/docs/framework/12-dissemination) and [Leveraging AI for analysis and interpretation](/en/apps/ai-assistant).

## Downloads in the app

| Where | What you get |
| --- | --- |
| Chart toolbar, **Download Plot** | The chart as a PNG image |
| Chart toolbar, **Download Data** | The numbers behind the chart as an Excel `.xlsx` file, with titled sheets |
| Table, **Download Data** | The table as Excel, for the year or indicator chosen in *This table only* |
| Overall Data Quality Score, Service Utilization DQA, National Health System | **Download Plot** (PNG) and **Download Data** (Excel) for the whole table |
| Load Data, **Download Master Dataset** | The merged dataset as a Stata `.dta` file |
| Data Adjustment, **Download Adjusted Dataset** | The adjusted dataset as a `.dta` file |

Some charts also offer tools in the card toolbar: edit the labels of one chart, change orientation, text size or legend position, adjust style (fonts, colours, gridlines) and expand the chart. **Customize this chart** lets you apply a setting to this chart, to every chart of the card, to every chart of the same type or to all charts, and to the screen, the report or both. Settings are saved with the dataset.

<Callout type="info">
Download the data with the plot when you share a chart. The Excel file carries the title and the numbers, so readers can check the figure.
</Callout>

## Reports

The **Reports** page in the **Output** section builds documents (Word or PDF) and slide decks (PowerPoint or PDF) from the loaded dataset, starting from the standard reports of this app or from a blank page. Charts and tables are redrawn from the data every time, and every report is saved in the dataset. The full guide, with each standard report, the editor, export formats and troubleshooting, is on the [Reports](/en/apps/rmncah/reports) page.

## Working with the DataSuite chat assistant

The DataSuite chat assistant works on the same saved dataset as the app, knows which page you are on, and answers from your data and the Countdown methodology, with its sources. What it can and cannot do, and good practice, are on the **[AI assistant](/en/apps/ai-assistant)** page.

<Steps>

### Finish loading the dataset

The assistant works on the saved `_rmncah.rds` dataset, which is created when you finish the Load Data wizard.

### Open the chat and ask

Examples: *List the pages of the RMNCAH app and what each one reads*, *Which regions have Penta3 coverage below 80% in the latest year, using the selected denominator?*, *Draft an interpretation of the national continuum of care for the review meeting*.

### Check the answer

Compare the numbers with the matching page in the app. The assistant ends its answer with its sources: the data it used and the methodology sections.

</Steps>

## Common pitfalls

- Sharing a chart without its data or the denominator. Always state the denominator and adjustment used.
- Asking the assistant about results before Data Adjustment has been run and saved in the app.
- Accepting an AI interpretation without checking data quality. The assistant reads the same data, so poor data give poor conclusions.
