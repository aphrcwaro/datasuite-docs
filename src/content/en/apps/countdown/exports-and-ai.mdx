# Exports, reports and AI

This page covers what you can take out of the app (images, tables, datasets and reports), how to build a report, and how the DataSuite chat assistant can analyse the same saved dataset. For planning what to do with the results, see [Dissemination, decisions and action](/en/docs/methodology/dissemination) and [Leveraging AI for analysis and interpretation](/en/apps/ai-assistant).

## Charts and tables

<Tabs items={['RMNCAH', 'Vaxx']} storageKey="countdown-app">
<Tabs.Tab>

| Where | What you get |
| --- | --- |
| Chart toolbar, **Download Plot** | The chart as a PNG image |
| Chart toolbar, **Download Data** | The numbers behind the chart as an Excel `.xlsx` file, with titled sheets |
| Table, **Download Data** | The table as Excel, for the year or indicator chosen in *This table only* |
| Overall Data Quality Score, Service Utilization DQA, National Health System | **Download Plot** (PNG) and **Download Data** (Excel) for the whole table |

Some charts also offer tools in the card toolbar: edit the labels of one chart, change orientation, text size or legend position, adjust style (fonts, colours, gridlines) and expand the chart. **Customize this chart** lets you apply a setting to this chart, to every chart of the card, to every chart of the same type or to all charts, and to the screen, the report or both. Settings are saved with the dataset.

</Tabs.Tab>
<Tabs.Tab>

Every chart has a toolbar in its card header:

| Tool | What it does |
| --- | --- |
| Ask AI | Placeholder for a future feature ("coming soon"). |
| View options | For this chart only: orientation (Auto or Swap axes), text size, legend position (Right, Bottom, Hidden). |
| Edit labels | Change the title, subtitle, caption, axis and legend titles of this chart. An empty field keeps the original text. Applies to the chart and its image download. Edited text is not translated. |
| Style options | Fonts, colours, angles, legend, axes, grid and background of this chart. Saved with the dataset. |
| Download Plot | Saves the chart as a PNG image. |
| Download Data | Saves the data behind the chart as an Excel file. |
| Expand chart | Enlarges the chart. |

Tables have a **Download Data** button (Excel). Tables with a year or indicator selector filter only that table, as the hint "This table only" says. The Overall Data Quality Score card has one button for the plot and one for the data.

Downloads follow what you see: the current indicator, admin level, region and denominator. The file name carries the indicator and denominator, for example `penta3_...`.

</Tabs.Tab>
</Tabs>

<Callout type="info">
How to share a chart so readers can check it: [Dissemination > Sharing charts and tables](/en/docs/methodology/dissemination#sharing-charts-and-tables).

## Reports

The **Reports** page in the **Output** section builds documents (Word or PDF) and slide decks (PowerPoint or PDF) from the loaded dataset, starting from the standard reports of this app or from a blank page. In the Vaxx app it needs adjusted data. Charts and tables are redrawn from the data every time, and every report is saved in the dataset. The full guide, with each standard report, the editor, export formats and troubleshooting, is on the [Reports](/en/apps/countdown/reports) page.

## The DataSuite chat assistant

The DataSuite chat assistant works on the same saved dataset as the app, knows which page you are on, and answers from your data and the Countdown methodology, with its sources. What it can and cannot do, and good practice, are on the **[AI assistant](/en/apps/ai-assistant)** page.

<Steps>

### Save your work

<Tabs items={['RMNCAH', 'Vaxx']} storageKey="countdown-app">
<Tabs.Tab>

Finish loading the dataset. The assistant works on the saved `_rmncah.rds` dataset, which is created when you finish the Load Data wizard.

</Tabs.Tab>
<Tabs.Tab>

Finish the wizard so that the dataset is saved as an `.rds` cache, and adjust the data.

</Tabs.Tab>
</Tabs>

### Ask a question

Open the chat and ask.

<Tabs items={['RMNCAH', 'Vaxx']} storageKey="countdown-app">
<Tabs.Tab>

Examples: *List the pages of the RMNCAH app and what each one reads*, *Which regions have Penta3 coverage below 80% in the latest year, using the selected denominator?*, *Draft an interpretation of the national continuum of care for the review meeting*.

</Tabs.Tab>
<Tabs.Tab>

For example: "Which districts have Penta1 to Penta3 dropout above 10 percent in the latest year?" or "Explain why the survey and DHIS2 Measles 1 coverage differ."

</Tabs.Tab>
</Tabs>

### Check the answer

The assistant ends its answer with its sources: the data it used and the methodology sections. Compare its numbers with the matching page and charts in the app before quoting them, and see the **[AI chapter](/en/apps/ai-assistant)** for good prompts.

</Steps>

## Common pitfalls

- Sharing results: see [Dissemination > Common pitfalls](/en/docs/methodology/dissemination#common-pitfalls).
- Asking the assistant about results before Data Adjustment has been run and saved in the app.
- Accepting an AI interpretation without checking data quality. The assistant reads the same data, so poor data give poor conclusions. AI output must be checked by an analyst. See **[Leveraging AI for analysis and interpretation](/en/apps/ai-assistant)**.

## Limits

- In the Vaxx app, the data reference lists the 18 Vaxx analysis pages (upload, data quality, preparation, denominators, coverage, inequality, equity and targets). It does not describe the Introduction and Reports pages.
- In the Vaxx app, Ask AI buttons in the chart toolbars are not active yet. Use the chat assistant instead.
