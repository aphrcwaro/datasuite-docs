# Exports, reports and AI

This page covers what you can take out of the Vaxx App (images, tables, datasets and reports) and how the DataSuite chat assistant can work with the same data. Dissemination planning is discussed in the **[dissemination chapter](/en/docs/framework/12-dissemination)**.

## Charts and tables

Every chart has a toolbar in its card header:

| Tool | What it does |
| --- | --- |
| Ask AI | Placeholder for a future feature ("coming soon"). |
| View options | For this chart only: orientation (Auto or Swap axes), text size, legend position (Right, Bottom, Hidden). |
| Edit labels | Change the title, subtitle, caption, axis and legend titles of this chart. An empty field keeps the original text. Applies to the chart and its image download. Edited text is not translated. |
| Style options | Fonts, colours, angles, legend, axes, grid and background of this chart. Saved with the dataset. |
| Download Plot | Saves the chart as a PNG image. |
| Download Data | Saves the data behind the chart as an Excel file. |
| Expand chart | Enlarges the chart. |

Tables have a **Download Data** button (Excel). Tables with a year or indicator selector filter only that table, as the hint "This table only" says. The Overall Data Quality Score card has one button for the plot and one for the data.

Downloads follow what you see: the current indicator, admin level, region and denominator. The file name carries the indicator and denominator, for example `penta3_...`.

## Datasets

| Download | Where | File |
| --- | --- | --- |
| Download Master Dataset | Load Data, Upload Data step | `master_dataset.dta`, the merged data as loaded |
| Download Adjusted Dataset | Data Adjustment, after **Adjust Data** | `master_adj_dataset.dta`, the adjusted data |

The wizard also saves the whole analysis as `name_vaccine.rds` (see **[Getting started](/en/apps/vaxx/getting-started)**). That file is the cache used by the AI tools below and by the **[Pooled App](/en/apps/pooled)**.

## Reports

The **Reports** page in the **Output** section builds documents (Word or PDF) and slide decks (PowerPoint or PDF) from the loaded dataset, starting from the standard reports of this app or from a blank page. It needs adjusted data. Charts and tables are redrawn from the data every time, and every report is saved in the dataset. The full guide, with each standard report, the editor, export formats and troubleshooting, is on the [Reports](/en/apps/vaxx/reports) page.

## The DataSuite chat assistant

The DataSuite chat assistant works on the same saved dataset as the app, knows which page you are on, and answers from your data and the Countdown methodology, with its sources. What it can and cannot do, and good practice, are on the **[AI assistant](/en/apps/ai-assistant)** page.

<Steps>

### Save your work

Finish the wizard so that the dataset is saved as an `.rds` cache, and adjust the data.

### Ask a question

For example: "Which districts have Penta1 to Penta3 dropout above 10 percent in the latest year?" or "Explain why the survey and DHIS2 Measles 1 coverage differ."

### Check the answer

The agent ends its answer with its sources. Compare its numbers with the app charts before quoting them, and see the **[AI chapter](/en/apps/ai-assistant)** for good prompts.

</Steps>

## Limits

- The data reference lists the 18 Vaxx analysis pages (upload, data quality, preparation, denominators, coverage, inequality, equity and targets). It does not describe the Introduction and Reports pages.
- Ask AI buttons in the chart toolbars are not active yet. Use the chat assistant instead.
- AI output must be checked by an analyst. See **[Leveraging AI for analysis and interpretation](/en/apps/ai-assistant)**.
