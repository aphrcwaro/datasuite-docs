# Getting started

## Open the app

Open DataSuite, go to the Start page and choose **Vaxx**. The app opens on the Introduction page, which presents the Countdown immunization coverage and inequalities project in English, French or Portuguese. Use **Load Data** in the left navigation to begin.

If you launch the app by opening a data file in DataSuite, that file is loaded for you.

## Accepted files

| Format | Notes |
| --- | --- |
| `.xlsx`, `.xls` | A workbook with an `Admin_data` sheet, a `Population_data` sheet, a `Reporting_completeness` sheet and at least one `Service_data` sheet. Starts the full walkthrough. |
| `.dta` | A single, already merged Stata file. |
| `.rds` | A dataset saved by this app. It is already validated, so the app opens a summary of the dataset instead of the walkthrough. |

Files of up to 2 GB are accepted. Other extensions are refused with "Upload failed: Unsupported file format."

When you upload an Excel or Stata file, the app looks for a saved copy named `name_vaccine.rds` and loads it instead if it exists. This is how work resumes. In a desktop session the copy sits next to your file; from a browser it is kept in a fixed local folder.

## The Load Data wizard

The wizard has a step rail. Steps unlock in order, and a step marked required must be complete before the next one opens.

<Steps>

### Upload Data

Drop or browse for your file in the **Dataset** card ("Browse or Drop..."). Under Additional reference data (optional) you can upload your own **UN estimates** and **WUENIC estimates** to replace the built-in reference datasets. **Download Master Dataset** saves the merged data as `master_dataset.dta`. Clearing the file also clears everything derived from it.

### Data Quality

Checks run automatically on the loaded sheets. Blocking checks must pass before you can continue:

- The Admin, Population and Service sheets are found.
- The country name is recognized, and the Admin sheet names exactly one country.
- The Admin sheet has country, admin-1 and district columns.
- Districts match between the Admin sheet and every other sheet, and district names are consistent across years.
- No month is missing for any district-year, and every month value is a recognized English or French month.

Informational checks do not block. They flag estimated live births below reported institutional counts, population figures that look pasted into service data, indicators with no data at all, and month names written differently across sheets. Two mapping checks report survey or shapefile region names that do not match your data.

### Survey Files (optional)

Upload the national, regional, area, maternal education and wealth quintile survey files (`.dta`), one at a time. Without them the app keeps its built-in reference data.

### National Rates

Confirm the survey coverage (percent, 0 to 100) for ANC1, institutional delivery, BCG, Penta1, Penta3, OPV1, OPV3 and Measles 1. Confirm the national rates (proportions, for example 0.03 for 3 percent, range 0 to 0.05) for pregnancy loss, twin births, stillbirth, neonatal mortality and post-neonatal mortality. Also confirm the Survey Data Start Year and Recent Survey Year. Values found in your national survey file are pre-filled, so check them. Every field is required.

### Shapefile (optional)

The standard shapefile for the country is used by default. To use your own, upload it and say which column holds the region (admin-1) names.

### Map Survey and Map Shapefile

When you uploaded survey files or a custom shapefile, match their region names to those in your dataset. Names are matched automatically where possible, but you must review and save the matches even if nothing needs correcting.

### Finish Loading Data

The dataset is saved and the wizard shows Ready for analysis, with a summary (rows loaded, checks passed, fields set, files uploaded, regions mapped). Choose **Continue to analysis**. Use **Edit** on the summary to return to any step.

</Steps>

## Common upload errors

| Message or symptom | Meaning and fix |
| --- | --- |
| Upload failed: Unsupported file format. | The extension is not `.xls`, `.xlsx`, `.dta` or `.rds`. |
| Upload failed: missing sheet(s) | The workbook lacks a required sheet. The missing names are listed. |
| Key Columns ... missing in ... | A sheet lacks a key column, for example the country or first admin level column of `Admin_data`. |
| Sheet ... is empty. | A required sheet has no rows. |
| Country contains multiple names. Please clean the data | The Admin sheet names more than one country. |
| The country in the document is not supported | The country name could not be matched. A "Did you mean" suggestion is shown, so correct the spelling. |
| This dataset was built for the 'rmncah' indicator group, but this app is for 'vaccine'. | You loaded a dataset saved by the RMNCAH App. Use that app, or start again from the original data. |
| Some checks found issues that need fixing before you can continue | A blocking Data Quality check failed. Fix the source file and upload it again. |
| Missing required files, or File does not match any known pattern | A survey file is missing or not recognized. |
| Review needed | Region name matches must be reviewed and saved before you continue. |

<Callout type="info">
If a saved `.rds` copy cannot be read, the app falls back to the original Excel or Stata file automatically.
</Callout>
