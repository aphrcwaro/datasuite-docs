## Downloading and installation [#faqs-download-install]

**Q. What are the system requirements for DataSuite?**

- Check out the list of [system requirements](/en/docs/setup/requirements).

**Q. How do I know which version of DataSuite I am running?**

- On the menu bar, click **Help** and select **About**.

![DataSuite About dialog showing the version number](/images/datasuite_version_check.jpg)

**Q. How do I manually check for DataSuite version updates?**

- On the menu bar, click **Help** and select **Check for Updates**.

![Help menu with the Check for Updates option highlighted](/images/datasuite_update_check.jpg)

**Q. How can I do a "clean" uninstall of DataSuite?**

- If you want to remove all user data after [uninstalling](/en/docs/setup/uninstall) DataSuite, you can delete the user data folders `DataSuite` and `.datasuite`.
- This returns you to the state before you installed DataSuite. This approach can also be used to reset all settings if you do not want to uninstall DataSuite.
- The folder locations vary depending on your platform:
  - **Windows**: delete `%APPDATA%\DataSuite` and `%USERPROFILE%\.datasuite`.
