# Framework overview

This page summarizes the CD2030 DataSuite analytical framework.
It is intended to help teams move from raw facility and survey data to defensible national and sub-national coverage findings.

![Countdown analysis workflow](/images/methods_cd_approach.png)

## End-to-end workflow

The framework follows a practical sequence:

1. [Load and configure](/en/docs/framework/1-analysis-setup) facility and survey data.
2. [Calibrate key national benchmark rates](/en/docs/framework/1-analysis-setup#survey-params).
3. [Assess data quality](/en/docs/framework/2-data-quality-assessment) before estimating coverage.
4. [Adjust](/en/docs/framework/3-data-adjustment) incomplete, unstable, or unreliable data.
5. [Select the best-performing denominator](/en/docs/framework/4-denominator-selection).
6. Generate and interpret **[coverage](/en/docs/framework/5-coverage-estimation)**, **[equity](/en/docs/framework/6-equity-analysis)**, **[sub-national](/en/docs/framework/7-subnational-analysis)**, **[mortality](/en/docs/framework/9-mortality)**, **[service utilization](/en/docs/framework/10-service-utilisation)** and **[health system performance](/en/docs/framework/11-health-system-performance)** results.
