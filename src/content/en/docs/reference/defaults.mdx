# Defaults and thresholds

The numbers the method uses -- default values, cut-offs and expected ranges -- in one place, grouped by analysis step. Each row says what the number is, whether it applies to RMNCAH analyses, vaccine analyses or both, how the apps use it, and which section of the [Countdown methodology](/en/docs/methodology) explains it.

The values are generated from the apps' code (cd2030.core), so they are what the apps use. Where the 2024 Countdown vaccination guidebook differs, the methodology page says so.
