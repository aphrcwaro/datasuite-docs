## Install DataSuite on Windows [#datasuite-install]

### Use the Windows installer

<Steps>

### Download the [DataSuite installer](/en/downloads) for Windows

### Once it is downloaded, run the installer (`DataSuiteUserSetup-{version}.exe`)

If prompted by User Account Control (UAC), click **Yes** to allow the app to make changes to your device.

### Accept the license agreement

Read through the End-User License Agreement (EULA). Select **I accept the agreement** and click **Next**.

![License agreement screen of the DataSuite installer](/images/install_accept_licence.jpg)

### Choose the installation location

Choose the destination folder where you want DataSuite to be installed. By default, DataSuite is installed under `C:\Users\{Username}\AppData\Local\Programs\DataSuite`. Click **Next** to proceed.

![Installation location screen of the DataSuite installer](/images/install_choose_location.jpg)

### Install and finish

Click **Install** to begin the process. Once the progress bar completes, click **Finish** to exit the setup wizard and launch DataSuite.

![Ready to install screen of the DataSuite installer](/images/install_datasuite.jpg)

</Steps>

### Use the ZIP file

1. Download the [DataSuite ZIP archive](/en/downloads).
1. Extract the ZIP archive, and run DataSuite from there.
