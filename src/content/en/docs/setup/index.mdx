# Setting up CD2030 DataSuite

CD2030 DataSuite currently runs on Windows operating systems. It is a lightweight platform, allowing you to install it or use a portable version and begin your data operations in a matter of minutes.

To get started, follow these step-by-step setup instructions:

<Steps>

### Review the [system requirements](/en/docs/setup/requirements)

- To ensure your hardware and computer configuration are supported.

### Download and install CD2030 DataSuite for your platform

- Select the correct [installer](/en/downloads#installer-options) option for your PC.
- [Install](/en/docs/setup/windows) the DataSuite app.

### Go to [Getting started with DataSuite](/en/docs/getting-started)

- To get a glimpse of the user interface (UI) and key features of CD2030 DataSuite.

</Steps>
