# Préparation des données

La préparation des données transforme les chiffres notifiés en un jeu de données prêt pour l'analyse, le jeu de données utilisé pour la couverture. Elle comprend trois pages : **Supprimer les années**, **Ajustement des données** et **Changements d'ajustement** (dans l'application RMNCAH, elles se trouvent dans la section **Qualité des données**). La méthode, les formules et les règles de gestion figurent dans [Ajustement des données](/fr/docs/methodology/data-adjustment).

<Callout type="important">
L'ajustement est obligatoire. C'est l'exécution de l'ajustement qui déverrouille les pages suivantes : dans l'application RMNCAH, les pages Dénominateurs et Analyse ; dans l'application Vaxx, les dénominateurs, la couverture, les inégalités, les cibles et les Rapports restent indisponibles tant que vous n'avez pas lancé **Ajuster les données** au moins une fois.
</Callout>

## Supprimer les années[#remove-years]

**Objectif.** Écarter les années dont les données ne sont pas fiables.

**Quand l'utiliser.** Quand supprimer une année, et quand la conserver : [Ajustement des données > Supprimer les années](/fr/docs/methodology/data-adjustment#supprimer-les-années).

<Steps>

### Ouvrez Supprimer les années

Dans l'application RMNCAH, la page se trouve sous **Qualité des données** dans la barre latérale. Décidez d'abord à partir des pages de [qualité des données](/fr/apps/countdown/data-quality).

### Sélectionner les années à supprimer

Dans **Sélectionner les années à supprimer**, les pastilles listent les années présentes dans les données. Sélectionnez-en une ou plusieurs.

### Appuyez sur Confirmer la suppression

Le message passe de *Aucune année n'a encore été supprimée* à *Les données des années suivantes ont été supprimées*, suivi des années. Pour rétablir une année, désélectionnez-la ou videz la sélection et confirmez de nouveau.

</Steps>

![Supprimer les années](/images/fr-dqa-remove-year.png)

La suppression intervient avant l'ajustement. Si vous avez déjà ajusté, relancez **Ajuster les données** après avoir modifié les années supprimées.

## Ajustement des données[#data-adjustment]

**Objectif.** Corriger la notification incomplète (rapports manquants) et les valeurs aberrantes extrêmes. Comment les valeurs manquantes, les valeurs aberrantes et le facteur K sont traités : [Ajustement des données > Méthode](/fr/docs/methodology/data-adjustment#méthode).

La page comporte deux cartes : **Facteurs K (Facteurs d'ajustement)** et la carte d'ajustement avec **Ajuster les données**, qui applique les corrections au jeu de données courant.

<Steps>

### Choisissez les facteurs K

<Tabs items={['RMNCAH', 'Vaxx']} storageKey="countdown-app">
<Tabs.Tab>

La carte **Facteurs K (Facteurs d'ajustement)** comporte quatre sélecteurs : **Facteur K CPN**, **Facteur K accouchement**, **Facteur K vaccins** et **Facteur K consultations externes**. Chacun propose 0, 0,25, 0,5, 0,75 et 1. Ce que suppose chaque valeur et comment choisir : [Ajustement des données > Configuration du facteur k](/fr/docs/methodology/data-adjustment#configuration-du-facteur-k).

</Tabs.Tab>
<Tabs.Tab>

La carte **Facteurs K (Facteurs d'ajustement)** comporte un **Facteur K ANC**, un **Facteur K Accouchement** et un **Facteur K Vaccins**, chacun à choisir parmi 0, 0,25, 0,5, 0,75 ou 1. La page affiche les valeurs enregistrées dans le jeu de données. Choisissez une valeur pour chacun des trois facteurs ; la valeur de départ, la valeur par défaut du guide et comment choisir : [Ajustement des données > Configuration du facteur k](/fr/docs/methodology/data-adjustment#configuration-du-facteur-k).

</Tabs.Tab>
</Tabs>

### Appuyez sur Ajuster les données

<Tabs items={['RMNCAH', 'Vaxx']} storageKey="countdown-app">
<Tabs.Tab>

Le message passe de *Jeu de données non ajusté* à *Ajustement en cours ...* puis *Données ajustées*. Faites-le même si vous laissez tous les facteurs à 0, car c'est ce qui déverrouille les pages d'analyse.

</Tabs.Tab>
<Tabs.Tab>

Choisissez **Ajuster les données** et attendez « Données ajustées ». La zone d'état affiche « Pas encore ajusté », puis « Ajustement en cours... », puis « Données ajustées ».

</Tabs.Tab>
</Tabs>

### Téléchargez le résultat si nécessaire

Une fois les données ajustées, **Télécharger l'ensemble de données ajusté** enregistre le jeu de données principal ajusté au format `.dta` (`master_adj_dataset.dta`).

### Examiner les changements

Ouvrez **Changements d'ajustement**.

</Steps>

<Callout type="warning">
Modifier les facteurs K ou les années supprimées annule le jeu de données ajusté. Appuyez de nouveau sur **Ajuster les données**, faute de quoi les pages d'analyse ne refléteront pas votre modification. Si l'ajustement échoue, le message indique la raison.
</Callout>

Comment est traité un mois de district dont la notification est inférieure à 75 % (ou manquante) : [Ajustement des données > Règles de seuil de données critiques](/fr/docs/methodology/data-adjustment/#règles-de-seuil-de-données-critiques).

![Sélection du facteur K](/images/fr-adjustment-kfactor.png)

## Changements d'ajustement[#data-adjustment-changes]

**Objectif.** Voir ce que l'ajustement a fait à chaque indicateur.

**Comment le lire.** La carte **Visualiser les effets des changements** comporte un onglet par indicateur. Chaque graphique compare le nombre d'événements (de l'indicateur) *avant* et *après* ajustement pour la complétude et les valeurs aberrantes, par année.

<Tabs items={['RMNCAH', 'Vaxx']} storageKey="countdown-app">
<Tabs.Tab>

Les onglets sont accouchements en établissement, naissances vivantes en établissement, Pentavalent 1, CPN 1 et consultations externes des moins de 5 ans, plus un onglet **Personnalisé** pour tout autre indicateur. Utilisez **Télécharger le graphique** et **Télécharger les données** dans la barre d'outils. **Générer le rapport** ouvre le rapport d'ajustement.

</Tabs.Tab>
<Tabs.Tab>

Les onglets sont **Naissances vivantes en établissement de santé**, **BCG**, **Pentavalent 1** et **Rougeole 1**, plus un onglet **Vérification personnalisée** avec un sélecteur d'indicateur.

Si les données n'ont pas été ajustées, le graphique utilise un facteur K de 0 pour tous les services : il montre alors seulement l'effet du traitement des valeurs aberrantes et manquantes.

</Tabs.Tab>
</Tabs>

![Avant et après l'ajustement](/images/fr-adjustment-before-after.png)

## Comment interpréter les résultats

Comment lire les graphiques avant/après : [Ajustement des données > Sorties d'ajustement](/fr/docs/methodology/data-adjustment#sorties-dajustement). Ce qu'il faut rapporter : [Ajustement des données > Rapport](/fr/docs/methodology/data-adjustment#rapport).

## Pièges courants

- Modifier les facteurs K, les années supprimées ou le seuil de performance affecte toutes les pages en aval. Relancez **Ajuster les données** et revérifiez les dénominateurs ensuite.
- Les rapports et les caches poolés doivent être construits à partir de données ajustées. Voir **[Pooled App](/fr/apps/pooled)**.

Les pièges dans le choix des facteurs K et la suppression d'années, et les indicateurs qui ne sont pas ajustés : [Ajustement des données > Pièges courants](/fr/docs/methodology/data-adjustment#pièges-courants).
