# Préparation des données

La préparation des données transforme les données rapportées en jeu de données utilisé pour la couverture. Elle comporte trois pages : **Supprimer les années**, **Ajustement des données** et **Changements d'ajustement**. Les règles sont expliquées dans le chapitre **[ajustement des données](/fr/docs/framework/3-data-adjustment)**.

<Callout type="important">
L'ajustement est obligatoire. Les dénominateurs, la couverture, les inégalités, les cibles et les Rapports restent indisponibles tant que vous n'avez pas lancé **Ajuster les données** au moins une fois.
</Callout>

## Supprimer les années

Utilisez cette page pour écarter les années dont les données ne sont pas fiables, par exemple une année presque sans notification ou une défaillance connue du système.

<Steps>

### Décider à partir des pages de qualité des données

Confirmez avec les pages **[qualité des données](/fr/apps/vaxx/data-quality)** qu'une année est inutilisable.

### Sélectionner les années

Dans **Sélectionner les années à supprimer**, choisissez une ou plusieurs années.

### Confirmer

Choisissez **Confirmer la suppression**. Le message indique alors « Les données des années suivantes ont été supprimées » et les énumère. Pour rétablir des années, videz la sélection et confirmez à nouveau (« Aucune année n'a encore été supprimée. »).

</Steps>

![Supprimer les années](/images/fr-dqa-remove-year.png)

La suppression intervient avant l'ajustement. Si vous avez déjà ajusté, relancez **Ajuster les données** après avoir modifié les années supprimées.

## Ajustement des données

La page comporte deux cartes.

**Facteurs K (Facteurs d'ajustement)** : un **Facteur K ANC**, un **Facteur K Accouchement** et un **Facteur K Vaccins**, chacun à choisir parmi 0, 0,25, 0,5, 0,75 ou 1. Le facteur K est le volume de services supposé des établissements qui ne notifient pas, par rapport à ceux qui notifient. La valeur par défaut du cadre est 0,25, et la page affiche les valeurs enregistrées dans le jeu de données.

**Ajuster** : **Ajuster les données** applique les corrections au jeu de données courant. L'ajustement porte sur les rapports manquants et les valeurs aberrantes extrêmes. La zone d'état affiche « Pas encore ajusté », puis « Ajustement en cours... », puis « Données ajustées ». Une fois les données ajustées, **Télécharger l'ensemble de données ajusté** enregistre `master_adj_dataset.dta`.

<Steps>

### Choisir les facteurs K

Choisissez une valeur pour chacun des trois facteurs. Gardez 0,25 sauf si vous avez des éléments montrant que les établissements qui ne notifient pas assurent une autre part des services, par exemple un large secteur privé qui notifie mal.

### Lancer l'ajustement

Choisissez **Ajuster les données** et attendez « Données ajustées ».

### Examiner les changements

Ouvrez **Changements d'ajustement**.

</Steps>

![Choix des facteurs K](/images/fr-adjustment-kfactor.png)

## Changements d'ajustement

Montre comment l'ajustement a modifié chaque indicateur. Sous **Visualiser les effets des changements**, les onglets sont **Naissances vivantes en établissement de santé**, **BCG**, **Pentavalent 1** et **Rougeole 1**, plus un onglet **Vérification personnalisée** avec un sélecteur d'indicateur. Chaque graphique compare le nombre de l'indicateur avant et après ajustement pour complétude et valeurs aberrantes.

Si les données n'ont pas été ajustées, le graphique utilise un facteur K de 0 pour tous les services : il montre alors seulement l'effet du traitement des valeurs aberrantes et manquantes.

![Avant et après ajustement](/images/fr-adjustment-before-after.png)

## Interprétation et pièges

- De petites différences avant et après sont normales. Un grand saut sur une année indique une notification très faible ou une valeur aberrante à revoir dans la **[Détection des valeurs aberrantes](/fr/apps/vaxx/data-quality)**.
- Selon le cadre, les mois ou districts dont la notification est inférieure à 75 % ne sont pas majorés : l'ajustement ne peut donc pas réparer des données très incomplètes. Envisagez de supprimer ces années.
- Modifier les facteurs K, les années supprimées ou le seuil de performance affecte toutes les pages en aval. Relancez **Ajuster les données** et revérifiez les dénominateurs ensuite.
- Les rapports et les caches poolés doivent être construits à partir de données ajustées. Voir **[Pooled App](/fr/apps/pooled)**.
