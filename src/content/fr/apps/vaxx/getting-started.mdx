# Prise en main

## Ouvrir l'application

Ouvrez DataSuite, allez à la page Démarrer et choisissez **Vaxx**. L'application s'ouvre sur la page Introduction, qui présente le projet Countdown sur la couverture vaccinale et les inégalités en anglais, en français ou en portugais. Utilisez **Charger les données** dans la navigation de gauche pour commencer.

Si vous lancez l'application en ouvrant un fichier de données dans DataSuite, ce fichier est chargé pour vous.

## Fichiers acceptés

| Format | Remarques |
| --- | --- |
| `.xlsx`, `.xls` | Un classeur avec une feuille `Admin_data`, une feuille `Population_data`, une feuille `Reporting_completeness` et au moins une feuille `Service_data`. Lance le parcours complet. |
| `.dta` | Un fichier Stata unique, déjà fusionné. |
| `.rds` | Un jeu de données enregistré par cette application. Il est déjà validé : l'application ouvre un résumé du jeu de données au lieu du parcours. |

Les fichiers jusqu'à 2 Go sont acceptés. Les autres extensions sont refusées avec « Échec du téléversement : format de fichier non pris en charge. »

Lorsque vous téléversez un fichier Excel ou Stata, l'application cherche une copie enregistrée nommée `nom_vaccine.rds` et la charge à la place si elle existe. C'est ainsi que le travail reprend. Dans une session de bureau, la copie se trouve à côté de votre fichier ; depuis un navigateur, elle est conservée dans un dossier local fixe.

## L'assistant Charger les données

L'assistant comporte une liste d'étapes. Les étapes se débloquent dans l'ordre, et une étape obligatoire doit être terminée avant l'ouverture de la suivante.

<Steps>

### Téléverser les données

Déposez ou parcourez votre fichier dans la carte **Jeu de données** (« Parcourir ou déposer... »). Sous Données de référence supplémentaires (facultatif), vous pouvez téléverser vos propres **estimations des Nations Unies** et **estimations WUENIC** pour remplacer les jeux de référence intégrés. **Télécharger le jeu de données principal** enregistre les données fusionnées sous `master_dataset.dta`. Effacer le fichier efface aussi tout ce qui en découle.

### Qualité des données

Les vérifications s'exécutent automatiquement sur les feuilles chargées. Les vérifications bloquantes doivent réussir avant de continuer :

- Les feuilles Admin, Population et Service sont trouvées.
- Le nom du pays est reconnu, et la feuille Admin ne nomme qu'un seul pays.
- La feuille Admin comporte les colonnes pays, admin-1 et district.
- Les districts correspondent entre la feuille Admin et toutes les autres feuilles, et les noms de district sont cohérents d'une année à l'autre.
- Aucun mois ne manque pour un district-année, et chaque valeur de mois est un mois reconnu en anglais ou en français.

Les vérifications informatives ne bloquent pas. Elles signalent des naissances vivantes estimées inférieures aux effectifs institutionnels rapportés, des chiffres de population qui semblent collés dans les données de service, des indicateurs sans aucune donnée et des noms de mois écrits différemment d'une feuille à l'autre. Deux vérifications de correspondance signalent les noms de région de l'enquête ou du fichier de forme qui ne correspondent pas à vos données.

### Fichiers d'enquête (facultatif)

Téléversez un à un les fichiers d'enquête nationaux, régionaux, par milieu de résidence, par éducation maternelle et par quintile de richesse (`.dta`). Sans eux, l'application conserve ses données de référence intégrées.

### Taux nationaux

Confirmez la couverture de l'enquête (en pourcentage, de 0 à 100) pour CPN1, accouchement en établissement, BCG, Penta1, Penta3, VPO1, VPO3 et Rougeole 1. Confirmez les taux nationaux (des proportions, par exemple 0,03 pour 3 %, plage de 0 à 0,05) pour la perte de grossesse, les naissances gémellaires, la mortinatalité, la mortalité néonatale et la mortalité post-néonatale. Confirmez aussi l'Année de début des données de l'enquête et l'Année d'enquête récente. Les valeurs trouvées dans votre fichier d'enquête nationale sont pré-remplies : vérifiez-les. Tous les champs sont obligatoires.

### Fichier de forme (facultatif)

Le fichier de forme standard du pays est utilisé par défaut. Pour utiliser le vôtre, téléversez-le et indiquez quelle colonne contient les noms de région (admin-1).

### Cartographier l'enquête et Cartographier le fichier de forme

Si vous avez téléversé des fichiers d'enquête ou un fichier de forme personnalisé, associez leurs noms de région à ceux de votre jeu de données. Les noms sont associés automatiquement lorsque c'est possible, mais vous devez vérifier et enregistrer les correspondances même si rien ne doit être corrigé.

### Terminer le chargement des données

Le jeu de données est enregistré et l'assistant affiche Prêt pour l'analyse, avec un résumé (lignes chargées, vérifications réussies, champs définis, fichiers téléversés, régions cartographiées). Choisissez **Continuer vers l'analyse**. Utilisez **Modifier** dans le résumé pour revenir à n'importe quelle étape.

</Steps>

## Erreurs de téléversement courantes

| Message ou symptôme | Signification et solution |
| --- | --- |
| Échec du téléversement : format de fichier non pris en charge. | L'extension n'est pas `.xls`, `.xlsx`, `.dta` ou `.rds`. |
| Échec du téléversement : missing sheet(s) | Il manque une feuille obligatoire au classeur. Les noms manquants sont listés. |
| Key Columns ... missing in ... | Il manque une colonne clé à une feuille, par exemple la colonne du pays ou du premier niveau administratif de `Admin_data`. |
| Sheet ... is empty. | Une feuille obligatoire ne contient aucune ligne. |
| Country contains multiple names. Please clean the data | La feuille Admin nomme plus d'un pays. |
| The country in the document is not supported | Le nom du pays n'a pas pu être associé. Une suggestion « Did you mean » s'affiche : corrigez l'orthographe. |
| This dataset was built for the 'rmncah' indicator group, but this app is for 'vaccine'. | Vous avez chargé un jeu de données enregistré par RMNCAH App. Utilisez cette application, ou repartez des données d'origine. |
| Certaines vérifications ont détecté des problèmes à corriger avant de continuer | Une vérification bloquante de Qualité des données a échoué. Corrigez le fichier source et téléversez-le à nouveau. |
| Fichiers requis manquants, ou le fichier ne correspond à aucun modèle connu | Un fichier d'enquête est manquant ou non reconnu. |
| Vérification requise | Les correspondances de noms de région doivent être vérifiées et enregistrées avant de continuer. |

<Callout type="info">
Si une copie `.rds` enregistrée est illisible, l'application revient automatiquement au fichier Excel ou Stata d'origine.
</Callout>
