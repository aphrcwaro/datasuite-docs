# Exports, rapports et IA

Ce guide explique comment extraire les résultats de RMNCAH App, comment construire un rapport et comment l'assistant de chat de DataSuite peut analyser le même jeu de données enregistré. Pour planifier l'utilisation des résultats, voir [Diffusion, décisions et action](/fr/docs/framework/12-dissemination) et [Exploiter l'IA pour l'analyse et l'interprétation](/fr/apps/ai-assistant).

## Téléchargements dans l'application

| Où | Ce que vous obtenez |
| --- | --- |
| Barre d'outils du graphique, **Télécharger le graphique** | Le graphique sous forme d'image PNG |
| Barre d'outils du graphique, **Télécharger les données** | Les chiffres du graphique dans un fichier Excel `.xlsx`, avec des feuilles titrées |
| Tableau, **Télécharger les données** | Le tableau au format Excel, pour l'année ou l'indicateur choisi dans *Ce tableau uniquement* |
| Score global de qualité des données, DQA de l'utilisation des services, Système de santé national | **Télécharger le graphique** (PNG) et **Télécharger les données** (Excel) pour tout le tableau |
| Charger les données, **Télécharger le jeu de données principal** | Le jeu de données fusionné sous forme de fichier Stata `.dta` |
| Ajustement des données, **Télécharger l'ensemble de données ajusté** | Le jeu de données ajusté sous forme de fichier `.dta` |

Certains graphiques offrent aussi des outils dans la barre d'outils de la carte : modifier les libellés d'un graphique, changer l'orientation, la taille du texte ou la position de la légende, ajuster le style (polices, couleurs, quadrillage) et agrandir le graphique. **Personnaliser ce graphique** permet d'appliquer un réglage à ce graphique, à tous les graphiques de la carte, à tous les graphiques du même type ou à tous les graphiques, et à l'écran, au rapport ou aux deux. Les réglages sont enregistrés avec le jeu de données.

<Callout type="info">
Téléchargez les données avec le graphique lorsque vous partagez un graphique. Le fichier Excel contient le titre et les chiffres, ce qui permet aux lecteurs de vérifier la figure.
</Callout>

## Rapports

La page **Rapports** de la section **Résultats** construit des documents (Word ou PDF) et des présentations (PowerPoint ou PDF) à partir du jeu de données chargé, en partant des rapports standard de cette application ou d'une page vierge. Les graphiques et tableaux sont redessinés à partir des données à chaque fois, et chaque rapport est enregistré dans le jeu de données. Le guide complet, avec chaque rapport standard, l'éditeur, les formats d'export et le dépannage, se trouve sur la page [Rapports](/fr/apps/rmncah/reports).

## Travailler avec l'assistant de chat de DataSuite

L'assistant de chat de DataSuite travaille sur le même jeu de données enregistré que l'application, sait sur quelle page vous êtes et répond à partir de vos données et de la méthodologie Countdown, en citant ses sources. Ce qu'il peut faire ou non, et les bonnes pratiques, sont présentés sur la page **[Assistant IA](/fr/apps/ai-assistant)**.

<Steps>

### Terminez le chargement du jeu de données

L'assistant travaille sur le jeu de données enregistré `_rmncah.rds`, créé lorsque vous terminez l'assistant Charger les données.

### Ouvrez le chat et posez votre question

Exemples : *Liste les pages de l'application RMNCAH et ce que chacune lit*, *Quelles régions ont une couverture Penta3 inférieure à 80 % lors de la dernière année, avec le dénominateur sélectionné ?*, *Rédige une interprétation du continuum des soins national pour la réunion de revue*.

### Vérifiez la réponse

Comparez les chiffres avec la page correspondante de l'application. L'assistant termine sa réponse par ses sources : les données utilisées et les sections de la méthodologie.

</Steps>

## Pièges courants

- Partager un graphique sans ses données ni le dénominateur. Indiquez toujours le dénominateur et l'ajustement utilisés.
- Interroger l'assistant sur des résultats avant que l'Ajustement des données ait été exécuté et enregistré dans l'application.
- Accepter une interprétation de l'IA sans vérifier la qualité des données. L'assistant lit les mêmes données ; de mauvaises données donnent donc de mauvaises conclusions.
