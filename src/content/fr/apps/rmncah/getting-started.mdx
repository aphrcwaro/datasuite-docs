# Démarrage

Ce guide vous conduit de l'ouverture de RMNCAH App dans DataSuite à un jeu de données prêt pour l'analyse. La méthodologie qui sous-tend ces étapes est décrite dans [Configuration de l'analyse](/fr/docs/framework/1-analysis-setup).

## Ouvrir l'application

<Steps>

### Lancer l'application depuis DataSuite

Sur la page d'accueil de DataSuite, choisissez **Ouvrir dans RMNCAH** (voir [Naviguer dans l'interface de DataSuite](/fr/docs/getting-started)). L'application a besoin d'un fichier pour travailler ; DataSuite vous demande donc d'en choisir un. Les types acceptés sont `.xls`, `.xlsx`, `.dta` et `.rds`.

Utilisez le classeur Excel du [Data Extractor](/fr/apps/data-extractor) la première fois, puis le fichier `.rds` enregistré ensuite.

### Vérifier que le fichier a été lu

Ouvrez **Charger les données** dans la barre latérale. Lorsque DataSuite transmet le fichier à l'application, il est lu automatiquement et une bannière verte **Téléversement réussi** indique le nom du fichier. Si la page affiche à la place une zone **Téléverser les données HFD**, choisissez le fichier à cet endroit.

</Steps>

![Chargement des données de routine](/images/rmncah-loading-data.jpg)

## Deux façons de parcourir Charger les données

- **Un fichier `.rds` repris** a déjà été validé. L'assistant est remplacé par une page **Prêt pour l'analyse** comportant une ligne par étape (par exemple *15 sur 15 champs renseignés*, *Utilisation du fichier de forme intégré*) et un lien **Modifier** qui rouvre n'importe quelle étape. **Continuer vers l'analyse** vous mène à Taux de notification.
- **Un nouveau fichier Excel ou Stata** passe par le parcours décrit ci-dessous. Une étape ne s'ouvre qu'après avoir appuyé sur **Continuer** (ou **Passer à**) à l'étape précédente. Les étapes marquées *facultatif* peuvent être ignorées.

## Les étapes de l'assistant

<Steps>

### Téléverser les données

La carte **Jeu de données** affiche le fichier chargé. **Télécharger le jeu de données principal** enregistre le jeu de données fusionné au format `.dta`.

La carte **Données de référence supplémentaires (facultatif)** vous permet de remplacer les jeux de référence intégrés du pays par vos propres fichiers `.dta` : **Téléverser les estimations des Nations Unies**, **Téléverser les estimations WUENIC** et **Téléverser les estimations de mortalité de l'ONU**. **Restaurer les valeurs par défaut** rétablit les données intégrées.

### Qualité des données

Les vérifications s'exécutent automatiquement. Une bannière indique soit *Toutes les vérifications ont réussi — aucun problème bloquant détecté*, soit *Certaines vérifications ont détecté des problèmes à corriger avant de pouvoir continuer*.

- **Vérifications bloquantes :** feuilles Admin, Population et Service trouvées ; colonnes pays, admin-1 et district présentes ; un seul pays, reconnu par son nom ; les districts correspondent entre la feuille Admin et toutes les autres feuilles ; noms de districts cohérents d'une année à l'autre ; aucun mois manquant (chaque district-année comporte les 12 mois) ; chaque nom de mois est reconnu (anglais ou français).
- **Vérifications informatives :** naissances vivantes estimées non inférieures aux naissances vivantes en établissement (marge de 10 %), données de population non collées dans les données de service, chaque indicateur contient des données, noms de mois libellés de façon cohérente d'une feuille à l'autre.
- **Vérifications de correspondance :** les noms de régions de l'enquête et du fichier de forme correspondent à votre jeu de données. Les écarts se corrigent dans les étapes de correspondance.

Corrigez les problèmes bloquants dans le classeur et chargez-le de nouveau.

### Fichiers d'enquête (facultatif)

Téléversez jusqu'à cinq fichiers `.dta` dans la carte **Dossier de données d'enquête** : **Données nationales**, **Données régionales**, **Données par zone**, **Données sur l'éducation maternelle** et **Données par quintile d'indice de richesse**. Ils alimentent l'analyse de l'équité, les lignes de comparaison avec l'enquête et les comparaisons infranationales. Un fichier illisible affiche *Échec du téléversement* avec la raison.

### Taux nationaux

Saisissez les valeurs d'enquête utilisées pour dériver les dénominateurs. Tous les champs sont obligatoires et **Continuer** reste désactivé tant que *Champs obligatoires restants* est affiché.

- **Référence de l'enquête :** **Année d'enquête récente** (2015 à 2030) et **Année de début des données de l'enquête**. Utilisez les deux enquêtes les plus récentes, par exemple 2018 lorsque des enquêtes existent pour 2008, 2013, 2018 et 2023.
- **Mère et nouveau-né :** couverture CPN1, CPN4, accouchement en établissement, taux de césarienne et faible poids à la naissance en pourcentages (0 à 100), et perte de grossesse, naissances gémellaires, mortinatalité, mortalité néonatale et mortalité post-néonatale en proportions (0 à 0,05 ; par exemple 0,03 signifie 3 %).
- **Vaccination :** couverture BCG, Penta1, Penta3 et Rougeole 1 en pourcentages.

Si vous avez téléversé un fichier d'enquête nationale, les valeurs sont préremplies et une bannière l'indique. Vérifiez-les. Les définitions figurent dans la [méthodologie](/fr/docs/framework/1-analysis-setup#survey-params).

![Taux nationaux pour le calcul du dénominateur](/images/fr-national-surveys.png)

### Fichier de forme (facultatif)

L'application utilise un fichier de forme intégré pour le pays. Pour utiliser le vôtre, téléversez les fichiers `.shp`, `.dbf`, `.shx` et `.prj`, choisissez la colonne qui contient les noms de régions (admin-1) et appuyez sur **Utiliser ce fichier de forme**.

### Cartographier l'enquête et Cartographier le fichier de forme

Lorsque les noms de régions de l'enquête ou du fichier de forme diffèrent de ceux de votre jeu de données, appuyez sur **Associer les noms de région**, corrigez les correspondances et enregistrez. Enregistrez au moins une fois, même si rien n'a dû être modifié. **Effacer la correspondance** permet de recommencer.

### Terminer

À la dernière étape, appuyez sur **Terminer le chargement des données**. L'application fusionne les feuilles, enregistre dans le même dossier une copie portant le nom de votre fichier suivi de `_rmncah.rds`, et affiche **Prêt pour l'analyse**.

</Steps>

<Callout type="info">
Lorsque vous rouvrez le même fichier Excel ou Stata, la copie `_rmncah.rds` enregistrée à côté est utilisée à la place. Supprimez cette copie si vous avez modifié le classeur et souhaitez le charger à nouveau.
</Callout>

## Dépannage

| Message | Cause et solution |
| --- | --- |
| Échec du téléversement : format de fichier non pris en charge. | Le fichier n'est pas de type `.xls`, `.xlsx`, `.dta` ou `.rds`. Convertissez-le ou exportez-le de nouveau. |
| Échec du téléversement : le fichier indiqué n'existe pas | Le chemin sélectionné est absent ou le fichier a été déplacé. Sélectionnez de nouveau le fichier. |
| Échec du téléversement suivi d'un détail | Le classeur n'a pas pu être lu, par exemple une feuille ou une colonne obligatoire est absente. Comparez-le à la liste des feuilles de l'étape Qualité des données. |
| Ce jeu de données a été construit pour le groupe d'indicateurs « vaccine », mais cette application est destinée à « rmncah ». | Un jeu de données enregistré par une autre application Countdown a été ouvert. Utilisez l'application correspondante ou chargez le classeur. |
| Certaines vérifications ont détecté des problèmes à corriger | Une vérification bloquante de Qualité des données a échoué. Lisez la ligne en rouge, corrigez le classeur, chargez-le de nouveau. |
| Terminez d'abord les étapes précédentes | Vous avez essayé de sauter une étape. Terminez ou ignorez l'étape en cours. |
| Certains noms de régions de l'enquête ne correspondent pas à votre jeu de données | Utilisez **Associer les noms de région** dans l'étape de correspondance. |
| Chargez et terminez un jeu de données pour déverrouiller cette page | Les pages d'analyse restent verrouillées tant que le chargement n'est pas terminé. |

Après le chargement, poursuivez avec [Qualité des données](/fr/apps/rmncah/data-quality).
