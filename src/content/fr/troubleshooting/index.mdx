# FAQ

Cette page est en cours de développement. Les questions fréquemment posées sur DataSuite sont regroupées par thème ci-dessous.

## Téléchargement et installation [#faqs-download-install]

**Q. Quelle est la configuration requise pour DataSuite ?**

- Consultez la liste de la [configuration requise](/fr/docs/setup/requirements).

**Q. Comment savoir quelle version de DataSuite j'utilise ?**

- Dans la barre de menus, cliquez sur **Aide** et sélectionnez **À propos**.

![Boîte de dialogue À propos de DataSuite affichant le numéro de version](/images/datasuite_version_check.jpg)

**Q. Comment rechercher manuellement les mises à jour de DataSuite ?**

- Dans la barre de menus, cliquez sur **Aide** et sélectionnez **Rechercher les mises à jour**.

![Menu Aide avec l'option Rechercher les mises à jour en surbrillance](/images/datasuite_update_check.jpg)

**Q. Comment effectuer une désinstallation « complète » de DataSuite ?**

- Si vous souhaitez supprimer toutes les données utilisateur après avoir [désinstallé](/fr/docs/setup/uninstall) DataSuite, vous pouvez supprimer les dossiers de données utilisateur `DataSuite` et `.datasuite`.
- Cela vous ramène à l'état antérieur à l'installation de DataSuite. Cette approche peut également servir à réinitialiser tous les paramètres si vous ne souhaitez pas désinstaller DataSuite.
- L'emplacement des dossiers varie selon votre plateforme :
  - **Windows** : supprimez `%APPDATA%\DataSuite` et `%USERPROFILE%\.datasuite`.

**Q. Je ne trouve pas le fichier de cache généré**

- Assurez-vous d'avoir [correctement configuré votre dossier de travail](/fr/docs/framework/1-analysis-setup#working-folder). Recherchez ensuite un fichier dont le nom respecte le format `Countryname_yyyymmddhhms.rds`. Exemple : `Somalia_202605241128.rds`.
