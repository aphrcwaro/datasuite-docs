# Prise en main de l'interface de CD2030 DataSuite

Cette page présente les différents écrans et vues, ainsi que des conseils pour naviguer dans CD2030 DataSuite lors d'une première utilisation.

Après avoir [téléchargé](/fr/downloads) et [installé](/fr/docs/setup/windows#datasuite-install) CD2030 DataSuite, vous verrez l'écran suivant :

![Page d'accueil de DataSuite avec les éléments de l'interface numérotés](/images/welcome-page-annotated.png)

Il comporte les éléments suivants :

<Steps>

### Page d'accueil (Welcome)

Il s'agit de l'écran d'accueil par défaut lorsque vous ouvrez DataSuite. Il offre :

- Un accès rapide aux applications principales
- Des points d'entrée pour les nouveaux utilisateurs et des liens vers des visites guidées

### Fichier (File)

Le menu **Fichier** donne accès aux actions et à la navigation au niveau de l'application.

Les principales fonctions comprennent :

- Afficher toutes les applications disponibles dans DataSuite
- Ouvrir ou passer d'un outil à un autre
- Gérer les éditeurs ouverts (fermeture des onglets)
- Quitter l'application

### Affichage (View)

Le menu **Affichage** contrôle la manière dont l'application est affichée et organisée.

Vous pouvez :

- Changer le thème de l'application (par exemple, mode clair/sombre)
- Effectuer un zoom avant ou arrière sur l'interface
- Ajuster la disposition et l'organisation des panneaux
- Modifier les paramètres de langue

### Aide (Help)

Le menu **Aide** donne accès aux ressources d'assistance et aux informations système.

Les principales fonctionnalités comprennent :

- Accéder à la documentation de DataSuite
- Vérifier la version actuelle de l'application et rechercher des mises à jour
- Consulter les informations techniques et développeur

### Ouvrir Data Extractor (Open Data Extractor)

Lance le Data Extractor, qui permet de se connecter à DHIS2, de mapper les indicateurs et de télécharger les données de routine des établissements de santé.

### Ouvrir dans RMNCAH (Open in RMNCAH)

Lance la RMNCAH App, qui permet de :

- Analyser les indicateurs de santé maternelle, néonatale, infantile et adolescente
- Générer des résultats analytiques et des rapports

</Steps>
