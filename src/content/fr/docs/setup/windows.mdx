## Installer DataSuite sur Windows [#datasuite-install]

### Utiliser le programme d'installation Windows

<Steps>

### Téléchargez le [programme d'installation de DataSuite](/fr/downloads) pour Windows

### Une fois téléchargé, exécutez le programme d'installation (`DataSuiteUserSetup-{version}.exe`)

Si le Contrôle de compte d'utilisateur (UAC) vous le demande, cliquez sur **Oui** pour permettre à l'application d'apporter des modifications sur votre appareil.

### Accepter le contrat de licence

Parcourez le Contrat de licence de l'utilisateur final (EULA). Sélectionnez **J'accepte le contrat** et cliquez sur **Suivant**.

![Écran du contrat de licence du programme d'installation de DataSuite](/images/install_accept_licence.jpg)

### Choisir l'emplacement d'installation

Choisissez le dossier de destination où vous souhaitez installer DataSuite. Par défaut, DataSuite est installé dans `C:\Users\{Username}\AppData\Local\Programs\DataSuite`. Cliquez sur **Suivant** pour continuer.

![Écran de l'emplacement d'installation du programme d'installation de DataSuite](/images/install_choose_location.jpg)

### Installer et terminer

Cliquez sur **Installer** pour lancer le processus. Une fois la barre de progression terminée, cliquez sur **Terminer** pour fermer l'assistant d'installation et lancer DataSuite.

![Écran d'installation prête du programme d'installation de DataSuite](/images/install_datasuite.jpg)

</Steps>

### Utiliser le fichier ZIP

1. Téléchargez l'[archive ZIP de DataSuite](/fr/downloads).
1. Extrayez l'archive ZIP et exécutez DataSuite à partir de là.
