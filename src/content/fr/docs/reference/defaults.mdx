# Valeurs par défaut et seuils

Les nombres qu'utilise la méthode -- valeurs par défaut, seuils et plages attendues -- réunis en un seul endroit, regroupés par étape de l'analyse. Chaque ligne indique ce qu'est la valeur, si elle s'applique aux analyses RMNCAH, aux analyses de vaccination ou aux deux, comment les applications l'utilisent, et quelle section de la [méthodologie Countdown](/fr/docs/methodology) l'explique.

Les valeurs sont générées à partir du code des applications (cd2030.core) : ce sont donc celles qu'utilisent les applications. Lorsque le guide de vaccination Countdown de 2024 diffère, la page de méthodologie le précise.
