# Référence rapide

La [méthodologie Countdown](/fr/docs/framework) est la méthode : chaque étape de l'analyse, comment elle se déroule et comment lire les résultats. Cette section sert à retrouver une information : quelle page couvre une étape, où elle se trouve dans les applications, ce que signifie un indicateur.
