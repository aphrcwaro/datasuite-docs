# Référence rapide

La [méthodologie Countdown](/fr/docs/methodology) est la méthode : chaque étape de l'analyse, comment elle se déroule et comment lire les résultats. Cette section sert à retrouver une information : quelle page couvre une étape, où elle se trouve dans les applications, ce que signifie un indicateur.

## Retrouver une information

- [Valeurs par défaut et seuils](/fr/docs/reference/defaults): les nombres de la méthode -- valeurs par défaut, seuils et plages attendues -- par étape, tels que les applications les utilisent
- [Formules](/fr/docs/reference/formulas): toutes les formules qu'utilise la méthodologie, avec la signification de chaque symbole
- [Analyses RMNCAH et vaccination](/fr/docs/reference/rmncah-vs-vaccine): les règles qui diffèrent entre une analyse RMNCAH (application RMNCAH) et une analyse de vaccination (application Vaxx), étape par étape, avec l'endroit où chacune est expliquée
- [Définitions des indicateurs](/fr/docs/reference/indicator-definitions): ce que mesure chaque indicateur et comment il est calculé
- [Justification scientifique](/fr/docs/reference/rationale): les données probantes derrière les analyses, et des détails complémentaires
